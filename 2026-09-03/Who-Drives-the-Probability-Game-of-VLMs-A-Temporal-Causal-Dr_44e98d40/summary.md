# 论文速读：Who Drives the Probability Game of VLMs? A Temporal Causal Drive Evaluation Framework

## 一句话总结
本文提出了一种基于结构因果模型（SCM）的**时序因果评估框架**，通过干预和后门调整推导出**三个逐Token步进的因果驱动指标**（PCD、QCD、VCD），在无需参考答案的情况下量化视觉输入、问题文本和已生成前缀对 VLM 自回归生成过程的因果贡献，揭示了"早期问答/视觉引导强 → 后期前缀依赖增强"的一致性生成动态模式。

## 研究问题与动机
1. **现有评估的盲区**：主流指标（BLEU、CIDEr、BERTScore、任务准确率）仅关注最终答案质量，无法揭示模型在生成过程中依赖了哪些信息源，导致难以诊断错误来源于视觉接地不足、问题理解偏差还是前缀错误累积。
2. **过程级分析的局限**：过程导向评估多集中于文本推理链的步级正确性与连贯性，在多模态场景下无法区分视觉、问题和历史前缀三类来源各自的作用。
3. **静态贡献估计的缺陷**：现有模态贡献量化方法（信息分解、相对熵等）仅提供全局/样本级重要性分数，无法刻画因果驱动在自回归生成中的**时间演化轨迹**。
4. **因果与相关混淆**：表面概率相关与深层因果关系紧密纠缠，直接观测条件概率会因混杂路径（如 $V \to Q \to A_t$）产生偏差，需引入因果干预实现去偏估计。

## 核心贡献（创新点）
1. **构建 VLM 生成的结构化因果图并形式化自回归解码为受问/图/前缀驱动的时序过程**，将因果驱动度量从"回答级相关性"推向"生成过程级因果归因"；与现有静态全局贡献估计的本质区别在于其**步进式时间粒度 + 因果干预校准**。
2. **推导出三个无需参考答案的因果驱动指标**（PCD / QCD / VCD），基于 do-operator 与后门调整计算干预后概率变化，而非观测条件概率；区别于 ReCEval、Temporalizing Confidence 等过程评估仅关注推理步骤正确性，三者**直接量化信息源对每个 Token 生成的因果驱动力**。
3. **揭示跨模型与跨数据集的一致性生成动态**：从早期较强问答/视觉引导向后期前缀依赖增强的稳定转移，并据此聚类出三种可解释的样本级生成模式；现有工作无法捕捉此类时序转移规律。
4. **通过随机化干预验证与外部基准 VLMBias 分类任务双重验证因果归因的有效性**：QCD/PCD 较观测 PMI 基线恢复误差分别降低 34.8% / 47.1%，前缀–视觉不平衡得分达到 0.767 AUROC；超越了仅依赖源移除探针的 sanity check 层面验证。

## 方法详解
- **结构因果图**：设定视觉节点 $V$ 为根节点，$V \to Q$（问题围绕图像构造）、$Q \to A_{\leq t}$、$V \to A_{\leq t}$、$A_{<t} \to A_t$（自回归传播）。$A_{<t}$ 与 $A_t$ 经 $Q,V$ 形成后门路径 $A_{<t} \leftarrow Q \to A_t$、$A_{<t} \leftarrow V \to A_t$；$Q$ 与 $A_{\leq t}$ 经 $V$ 形成混杂路径 $Q \leftarrow V \to A_{\leq t}$。
- **共同零源参考**：$P_0(A_{\leq t}) = P(A_{\leq t} \mid V=\emptyset, Q=\emptyset)$，提供三指标的统一尺度校准基准。
- **PCD（前缀因果驱动）**：对前缀做干预 $do(A_{<t}=a_{<t})$，对 $V,Q$ 做后门调整，得到：
  $\text{PCD}_t = \log_2 \frac{\sum_{v,q} P(V=v)P(Q=q\mid V=v)\cdot P(A_t=a_t\mid A_{<t}=a_{<t}, V=v, Q=q)}{P_0(A_{\leq t})}$
- **QCD（问题因果驱动）**：干预 $do(Q=q)$ 切断 $V\to Q$，对 $V$ 做后门调整：
  $\text{QCD} = \log_2 \frac{\sum_v P(V=v) P(A_{\leq t}\mid V=v, Q=q)}{P_0(A_{\leq t})}$，其中分子按自回归链式法则展开为逐 Token 概率乘积。
- **VCD（视觉因果驱动）**：联合干预 $do(V=v), do(Q=\emptyset)$，因 $V$ 为根节点无需后门调整：
  $\text{VCD} = \log_2 \frac{P(A_1\mid V=v,Q=\emptyset)\cdot\prod_{i=2}^t P(A_i\mid A_{<i}, V=v, Q=\emptyset)}{P_0(A_{\leq t})}$
- **有限支撑估计**：边缘分布权重 $P(V)$ 与 $P(Q\mid V)$ 由评测数据经验估计，支撑大小取 $K=20$；通过 teacher-forcing 评分实现各干预条件概率估计，避免昂贵且不稳的反事实解码。
- **计算复杂度**：PCD 最重 $O(|V|\cdot|Q|\cdot T)$，QCD 为 $O(|V|\cdot T)$，VCD 最轻 $O(T)$。

## 实验与结果
- **数据集**：MAVIS（500 样本，图像 VQA）、LLaVA-Video-178K（100 样本，监督视频 QA）、MiraData（500 样本，开放式视频 QA）、VLMBias（170 有效样本的二分类验证集）。
- **模型**：Qwen3-VL-8B-Instruct（主实验）、InternVL2-8B（跨模型验证）、Qwen3-VL-32B-Instruct（扩展性验证）。
- **时序转移发现**：三指标均呈现一致的"早期 QCD/VCD 较强 → 后期 PCD 上升"的转移模式；视频 QA（MiraData/LLaVA-Video）中 QCD 衰减更慢。
- **生成模式聚类**（k=3，30 维特征）：
  - Cluster 1（74%）前缀驱动，视觉影响弱化；
  - Cluster 2（6%）视觉抑制，VCD 全程为负；
  - Cluster 3（20%）多源协同，VCD/QCD/PCD 均维持高位。
- **随机化干预验证**：QCD 相对 $\text{PMI}_Q$ 恢复误差降低 **34.8%**（7.822→5.434 bits），PCD 相对 $\text{PMI}_P$ 降低 **47.1%**（3.660→2.019 bits）；QCD 在 98% 目标上优于基线，PCD 在所有目标上均优。
- **VLMBias 外部验证**：前缀–视觉不平衡得分 $S_{PV}$ 达到 **0.767 AUROC / 0.873 AUPRC**；答案级 VCD 单独达到 0.747 AUROC / 0.842 AUPRC。
- **源移除探针**：去除 $A_{<t}$ 使均值 Token 概率从 0.7167 降至 0.0323（100% 样本下降），去除 Q 降至 0.4384（99%），去除 V 降至 0.6541（73%）。
- **与传统指标关系**：QCD/VCD 与 BERT-F1、BLEU-4 呈弱正相关（Spearman ≈ 0.2），PCD 几乎无相关，三者为**互补信号**而非替代。

## 相关工作脉络
1. **结果级评估基线**（BLEU/CIDEr/BERTScore/任务准确率）：本文定位为补充过程诊断而非替代；本文方法与 ReCEval（推理步骤正确性）、Temporalizing Confidence（置信度轨迹）、THINK-Bench（推理效率）形成对比，后者聚焦文本链，本文同时分离视觉/问题/前缀三类因果贡献。
2. **模态贡献量化**（部分信息分解、相对熵、信息增益）：这些方法给出表示层或全局重要性估计，无法捕捉自回归过程中的时序动态；本文通过因果干预与时间步进弥补这一空白。
3. **多模态幻觉与视觉接地**（Grounded CoT 等）：现有工作关注幻觉检测或视觉证据支持，但未量化生成过程中各类来源的实时因果权重；本文通过 VCD/QCD/PCD 轨迹提供细粒度诊断。
4. **因果推断与语言模型**（CausalM、Pearl SCM）：本文将结构化因果模型引入 VLM 生成评估，通过 do-operator 和反事实概率分解实现因果归因，区别于仅使用观测条件概率的 PMI 基线。
5. **VLMBias 类偏见基准**：本文利用 VLMBias 的前缀驱动 vs 视觉接地标注验证因果驱动的识别能力，将因果指标与行为模式进行外部对齐，是评估框架有效性的重要验证路径。
6. **过程导向推理评估**：与 Let's Verify Step by Step、Evaluating Mathematical Reasoning Beyond Accuracy 等工作同属过程评估范式，但本文聚焦多模态源级归因而非纯文本推理链质量。

## 局限性与未来方向
1. **因果驱动≠答案正确性**：强视觉驱动仅表明概率支持来自视觉证据，不保证视觉理解正确；指标诊断源依赖而不替代正确性评估。
2. **SCM 假设的边界**：因果解释依赖于所设定的结构图、评估期间固定模型参数，以及未纳入的样本级共因已被调整的变量覆盖的假设，可能存在未观测混杂。
3. **模型与任务泛化**：实验集中于 Qwen3-VL 和 InternVL 系列及给定设置；Chain-of-Thought 风格的长推理生成尚未验证，为重要未来方向。
4. **计算开销**：PCD 复杂度最高，支撑集增大时显存与时间成本显著增加，限制了在大规模评测中的直接应用。

## 研究启发与可借鉴点
1. **因果干预评估范式可迁移至 LLM 推理链分析**：将 do-operator + 后门调整用于评估问题、上下文、历史推理步对 LLM 生成的因果贡献，有望揭示 CoT 推理中"哪一步骤真正驱动后续推导"的诊断能力。
2. **三步因果驱动轨迹 + k-means 聚类模式识别流程可直接复用**：本文从 30 维时序特征聚类出可解释生成模式的流水线，适用于分析其他多模态/多源模型的内部行为差异。
3. **随机化干预恢复误差作为因果指标的有效验证新范式**：将 PMI 等观测基线与因果驱动对比，在独立采样语境下测量恢复误差，提供了超越传统相关性分析的因果验证手段。
4. **前缀–视觉不平衡得分可用于模型鲁棒性分析**：$S_{PV} = \overline{PCD} - \overline{VCD}$ 简洁有效，可推广至检测模型在分布外或对抗场景下的来源依赖偏移。
5. **多源去偏策略可指导模型改进**：发现 Cluster 2（视觉抑制）和 Cluster 1（前缀过度依赖）两类问题模式后，可针对性设计视觉增强训练或前缀正则化策略，为模型迭代提供明确优化方向。

## 关键术语表
**结构因果模型（SCM）**：用有向图表示变量间因果关系的数学框架，通过 do-operator 和路径分析区分因果效应与统计相关。
**后门调整（Backdoor Adjustment）**：在因果图中阻断所有从处理变量到结果变量的后门路径（经混杂因子），从而无偏估计因果效应的方法。
**do-operator**：表征对某变量强制赋值的干预操作，切断其所有入边，使目标变量不再受上游因果机制影响。
**Prefix Causal Drive（PCD）**：在前缀被固定干预条件下，当前 Token 概率相对于零源参考的对数比，衡量已生成历史对当前生成的因果推动力。
**Question Causal Drive（QCD）**：对问题做干预并对视觉做后门调整后，生成序列概率相对于零源参考的对数比，量化问题信息的因果驱动。
**Visual Causal Drive（VCD）**：在固定视觉输入并消除问题信息条件下，生成序列概率相对于零源参考的对数比，表征视觉证据的因果贡献。
**随机化干预恢复误差**：在独立采样的语境下比较因果驱动估计与实际模型行为的平均绝对偏差，用于验证因果指标的可靠性。
**前缀–视觉不平衡得分（$S_{PV}$）**：平均 PCD 与平均 VCD 之差，用于区分前缀驱动与视觉接地生成行为。
