# 论文速读：LVS-LOCAL-VIEW-SYNTHESIS-FROM-RELATIVE-CAMERA-POSE-BY-REUSIN

## 一句话总结
本文提出了一种面向静态场景的局部视角合成框架 LVS，通过复用已渲染的 RGB-D 图像并结合相对相机位姿进行几何扭曲，再由轻量级多尺度网络预测 RGB 残差以修正伪影与补全新暴露区域，从而避免对相邻视角的重复完整渲染，实现了毫秒级低延迟的交互式场景探索。

## 研究问题与动机
1. **计算冗余问题**：交互式场景探索需频繁更新视角，传统 3DGS 等方法每次查询均需重新渲染整个场景，忽略了小范围相机移动时大量可见内容重叠的计算冗余。
2. **纯几何复用的局限**：直接复用已有渲染图像仅靠几何扭曲无法恢复视差变化带来的新暴露内容，且对深度误差、重采样失真及视角依赖的外观变化敏感。
3. **现有方法的权衡困境**：CheapNVS、AdaMPI32 等单源/少目方法在画质、计算开销与显存占用之间难以兼顾，缺乏将几何传输与外观残差校正明确解耦的轻量级方案。
4. **目标定位**：将“场景渲染”与“局部视角更新”解耦，在保证高画质的同时将单次查询延迟降至毫秒级，支撑 AR/VR 等实时导航应用。

## 核心贡献（创新点）
1. **提出相对位姿引导的已渲染 RGB-D 图像复用框架**：将局部视角合成转化为“几何扭曲 + 残差校正”的两阶段过程，彻底避免重复调用 3DGS 渲染器。
2. **设计融合缓存源特征与全分辨率几何/覆盖度线索的多尺度残差网络**：编码器一次性提取源特征并缓存，解码器结合扭曲图像、像素差异、覆盖度图及位姿 twists 逐层预测残差，支持多次目标查询的高效复用。
3. **实现渲染与局部更新的工程解耦，并在多数据集上验证低延迟与高质量**：在 GS-render、Blender 和 7-Scenes 上均取得最高 PSNR/SSIM，查询延迟仅约 0.95–0.98 ms，显存与参数规模显著低于对比方法。

## 方法详解
- **相对位姿引导的重投影（Geometric Warping）**：给定源图像 $I_1$、深度 $D_1$、相机内参 $K$ 及逆目标到源运动的六维 twist $p$，通过 $ \widetilde { y } \sim K \big [ Q \big ( \bar { D } _ { 1 } ( x ) K ^ { - 1 } \widetilde { x } \big ) + t \big ] $ 将源像素映射到目标坐标系（深度经缺失值填充与局部逆深度平面拟合）。颜色经双线性 splatting 并按深度过滤，累积权重构成覆盖度图 $C \in [0,1]$，最终得到几何扭曲图像 $I_w = \mathscr{W}(I_1, D_1, K, p)$；无投影支持的像素直接保留 $I_1$。
- **多尺度残差细化网络（Residual Refinement）**：编码器 $\mathrm{Enc}$ 从 $I_1$ 提取可复用特征 $F_1 = \mathrm{Enc}(I_1)$。定义 RGB 差分图 $\Delta W = I_w - I_1$。解码器 $\mathrm{Dec}$ 在 1/4 分辨率处拼接线性嵌入的 $I_w, \Delta W, C$ 与广播的 $p$，再与 $F_1$ 融合；自半分辨率至全分辨率逐步细化，并通过跳跃连接传入 $I_1, I_w, \Delta W, C$ 保留空间细节；末端单线性层输出残差 $R$，最终预测 $\widehat { I } _ { 2 } = I _ { w } + R$。
- **训练与源特征缓存机制**：采用 Charbonnier 损失 $\mathcal{L} = \mathrm{mean}\left( \sqrt{(\widehat { I } _ { 2 } - I _ { 2 } )^2 + \epsilon^2} \right)$ 进行端到端训练（$\epsilon = 10^{-3}$）。RGB 头零初始化使初始预测等于 $I_w$，保障训练稳定性。推理时，每个静态场景仅需缓存一次 $F_1$ 与几何预处理结果，后续每次新视角查询仅执行重投影、残差解码与合成，消除重复计算。

## 实验与结果
- **数据集与设置**：GS-render（3 个 Mip-NeRF 360 场景）、Blender（Barcelona Pavilion）及真实采集的 7-Scenes。图像分辨率 640×480，最大视角变化 15°，源视图与目标视图集合互斥。评估 PSNR、SSIM、LPIPS，硬件平台为 RTX 5090（FP32，batch=1，CUDA synchronization）。
- **主要结果**：在 GS-render 上，Ours 取得 26.89 dB PSNR / 0.841 SSIM，较第二强基线 AdaMPI32 提升 1.00 dB，LPIPS 更低；在 Blender 上以 30.57 dB PSNR / 0.882 SSIM 刷新最优；在 7-Scenes 上以 20.74 dB PSNR 略胜 AdaMPI32（20.47 dB），仅 LPIPS 略高。
- **组件消融**：纯几何扭曲（Warp-only）PSNR 为 26.17，加入全分辨率残差网络后提升至 26.89，绝对增益 0.72 dB；仅靠网络无几何引导（Pure Network）严重退化至 19.66 dB，验证了深度驱动扭曲的核心价值。分辨率消融表明 1/4 → 1/2 → Full 逐级提升。
- **视角范围与计算开销**：小角度范围内 Ours 显著优于 3DGS，但在 15° 时 PSNR 被 3DGS 反超，LPIPS 仍保持优势，说明单源复用存在视角上限。查询延迟稳定在 0.95–0.98 ms，参数仅 0.11M，源缓存 14.4 MiB，峰值显存 95.8 MiB，远低于 AdaMPI32 的 7697.1 MiB 峰值与 3DGS 的 518–582 MiB。
