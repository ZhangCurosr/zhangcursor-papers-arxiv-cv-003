# 论文速读：MEMENTO-3-Model-Based-Recursive-Self-Improvement-through-Ref

## 一句话总结
论文提出 MEMENTO 3，一种基于“代码即模型”（Code as Model）的递归自我改进方法：冻结 LLM 智能体通过持久化自然语言规则手册与可执行代码的外部记忆，在未知环境中持续观察、反思、修订并编译世界模型，从而在 ARC-AGI-3 上以 44% 人类行动次数达成全部关卡通关，并在 Atari Pong 中实现无需 LLM 调用的反馈控制。

## 研究问题与动机
- 智能体进入未知环境时需推断动态规则与目标，但有限交互历史只能支持多个一致的世界模型假设，如何持续修正泛化假设是关键挑战。
- 现有 Memento 系列主要聚焦策略/程序记忆改进，缺乏对显式世界模型的系统性学习与验证机制。
- 基于参数的世界模型（如神经网络）难以进行语义级修订与精确验证，而可执行代码可提供可检查、可规划的显式动态表示。
- 单假设规划易陷入自证偏误，需探索如何维持多个兼容假设以提升探索多样性与鲁棒性。

## 核心贡献（创新点）
- **提出 Code as Model 框架**：将外部学习状态定义为（交互历史 H、规则手册 ψ、可执行代码 θ）三元组，使世界模型假设可持久化、可修订、可执行。
- **设计反射式学习闭环**：通过观察→反思→规则修订→编译→验证五步循环，利用预测误差驱动模型迭代，而底层 LLM 参数始终保持冻结。
- **引入种群扩展机制**：并行维护 N 个规则手册-可执行代码对并共享交互历史，按行为等价类采样以引导探索，降低对单一初始假设的依赖。
- **在 ARC-AGI-3 上实现全通关与人类效率天花板**：单模型智能体完成全部 25 个游戏的 183 个关卡，平均 RHAE 达 100.0，仅用 44% 人类行动次数。
- **证明方法可迁移至连续反馈控制**：在 Atari Pong 中，学习到的世界模型支撑反馈控制器在不调用 LLM 的情况下以 21:0 获胜，学习成本仅为 RL 基线的约 1/42,000。

## 方法详解
- **环境建模**：将环境形式化为确定性目标导向 POMDP，转移函数 T、观测函数 ρ、目标集 G 均未知，智能体仅能访问动作接口与交互反馈。
- **外部学习状态**：Z_t = (H_t, ψ_t, θ_t)，其中 H_t 为交互轨迹记录，ψ_t 为自然语言规则手册（语义记忆），θ_t 为可执行代码（实现动态预测、目标检测与状态重建）。
- **反射式学习循环**：
  1. **观察**：执行动作 a_t 得到新观测 o_{t+1}，追加至 H_t。
  2. **反思**：冻结 LLM 判断应保留当前假设、修订规则手册还是仅修复代码实现。
  3. **规则修订**：若修订，LLM 生成新规则手册 ψ̃；若仅修复代码，则 ψ̃ = ψ_t。
  4. **编译**：规则导向编译器 C_φ 从 ψ̃、旧 θ_t 与 H_t+1 生成可执行代码 θ̃。
  5. **验证**：精确重放 H_t+1 检查预测观测是否完全匹配，并由 LLM 评估 θ̃ 与 ψ̃ 的语义保真度；仅当两者均通过时接受 (ψ̃, θ̃) 作为新假设。
- **规划与行动选择**：单模型下，以 δ 点分布近似信念，从重放重建的内部状态出发，在 θ 定义的转移图上搜索最短路径至目标集；无可行计划时则探索。
- **种群扩展**：维护 N 个兼容对，按行为等价类均匀采样代表模型的计划执行；所有观测更新共享历史，触发对冲突模型的反射-修复流程。

## 实验与结果
- **基准与设置**：ARC-AGI-3 全部 25 个公开游戏，评分为 level-weighted RHAE（满分 100）；实验基于 baseline1 代码库，使用 Claude Opus 5 + extra-high 推理。
- **主要结果**：单模型智能体通关全部 183 个关卡，平均 RHAE 100.0，总行动次数 7,518（人类基线 17,135 的 44%）；相比最强基线 baseline1（RHAE 99.0，8,347 次行动）提升 59.3 点 RHAE 并减少约 10% 行动消耗。
- **消融实验**：移除规则手册后，在三档难度游戏（ft09、ka59、cn04）上仍通关，但行动次数增加 9%（617 vs 677），智能体回合数增加 18%（678 vs 830），证明规则手册加速收敛。
- **种群扩展实验**：在 wa30 游戏上 N=2 相比 N=1，总行动次数从 899 降至 597（-34%），8/9 关卡效率持平或提升。
- **Atari Pong 案例**：学习到的反馈控制器在三个不同开局 episode 中均以 21:0 获胜；学习成本仅 9,504 帧，分别为 GDI/LASER/IMPALA/Rainbow（~2×10^8 帧）的约 1/21,000，以及 EfficientZero V2（~4×10^5 帧）的约 1/42。

## 相关工作脉络
- **世界模型与可执行表示**：Dyna、神经世界模型等参数化方法难以语义修订；本项目以可执行代码替代隐式表示，支持精确验证与规划。
- **语言引导程序归纳**：Parsel、Hypothesis Search、WorldCoder 等利用语言辅助程序生成；本项目进一步引入反射循环与编译验证，并分离规则与实现。
- **ARC-AGI-3 系统**：baseline1、OPINE-World、Twin 等同样结合模型构建与规划；本项目独特贡献在于持久化自然语言规则手册作为语义记忆，并支持规则/代码分离修订。
- **反射记忆与语言规则**：Reflexion、AutoManual、WALL-E 等使用语言记忆改进决策；本项目将记忆对象从策略侧扩展至模型侧。
- **模型不确定性与探索**：版本空间、最小描述长度、后验采样等理论被借鉴；本项目以种群机制近似版本空间，而非校准后验。
- **持续智能体适应**：Workspace Optimization、Continual Harness 等编辑智能体自身工件；本项目聚焦环境世界模型的学习，而非智能体架构修改。

## 局限性与未来方向
- 当前方法假设环境为确定性 POMDP，扩展至随机动态或观测噪声环境需引入概率建模。
- 规则手册随交互增长可能变得冗长，如何在保持表达力与简洁性之间平衡有待研究。
- 种群规模 N 的选择缺乏自适应机制，计算开销随 N 线性增长，需探索动态维护策略。
- 验证仅依赖精确重放，对于高维连续状态空间（如图像像素级）可能过于严格，需考虑容错匹配。
- 方法高度依赖底层 LLM 的反思与编译能力，LLM 幻觉或推理错误可能导致无效修订循环。

## 研究启发与可借鉴点
- **反射式学习闭环设计**可迁移至任何需要持续适应的冻结 LLM 智能体系统，尤其是具有显式状态转移的任务。
- **规则手册与可执行代码分离**为可解释 AI 提供新范式：抽象规则便于人类审阅与修正，代码实现保证执行效率。
- **精确重放验证**作为模型接受的硬约束，显著提升了训练过程的可靠性，可应用于程序合成、机器人仿真等领域。
- **种群采样探索**机制可用于解决版本空间歧义，在强化学习、游戏 AI 等样本敏感场景中提升探索效率。
- **Git 记忆**将整个学习轨迹版本化，便于回溯、diff 与恢复，为智能体的长期知识管理提供了工程实践参考。

## 关键术语表
- **Code as Model**：将环境世界模型表示为自然语言规则手册与可执行代码的配对，支持预测、规划与迭代修订。
- **反射式学习（Reflective Learning）**：智能体基于交互反馈对现有假设进行批判性评估，并生成改进方案的认知过程。
- **外部学习状态（External Learning State）**：存储交互历史、规则手册与可执行代码的持久化记忆结构，使冻结 LLM 能够持续学习。
- **相对人类行动效率（RHAE）**：评估智能体完成任务所用行动次数相对于人类专家行动次数的效率指标，满分为 100。
- **精确重放验证（Exact Replay Verification）**：将记录的动作序列输入可执行模型，逐帧比对预测观测与实际观测，确保模型一致性。
- **版本空间（Version Space）**：所有与观测历史一致但可能对未观测状态做出不同预测的假设集合。
- **后验采样（Posterior Sampling）**：从当前后验分布中随机采样一个世界模型，并在 episode 中固定使用该模型进行探索的 RL 方法。
- **递归自我改进（Recursive Self-Improvement, RSI）**：智能体利用自身能力改进支撑其推理、规划与学习的组件，形成持续增强闭环。

## 可复现要素
- **数据集**：ARC-AGI-3 公开游戏集（25 个游戏）；Atari Pong 使用 Arcade Learning Environment（ALE，帧跳过 4）。
- **代码开源情况**：实验基于 baseline1 代码库构建，论文未公开完整代码仓库；智能体运行环境为 Claude Code 搭配 Claude Opus 5。
- **关键超参数**：推理努力设置为 extra-high；种群大小 N=2（仅在 wa30 游戏验证）；帧跳过设置为 4（Atari Pong）。
- **环境接口限制**：智能体仅能访问动作界面与交互历史，无法读取环境源代码或获取任务描述。
