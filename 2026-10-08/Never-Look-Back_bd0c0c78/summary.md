# 论文速读：Never-Look-Back

## 一句话总结
论文提出了 **LEDGER**，一种可从首人称视频离线构建的持久化3D物体记忆系统，将物体的3D位置、运动历史和上下文描述统一存储为结构化文本记录，使代理在无需回放原始视频的情况下即可回答空间查询问题。

## 研究问题与动机
- **核心问题**：人类能在离开场景后仍回忆物品位置或容器内容，且不依赖重新回放经历；如何让具身代理从首人称视频建立类似的持久化空间记忆？
- **现有方法的不足**：
  - 仅记录手部交互物体的记忆（如 OSNOM、AMEGO）会遗漏始终可见但不被触碰的物体（如固定装置），而这些物体在空间查询中至关重要。
  - 仅有位置记录的存储无法保留物体的运动历史、容器内容或支撑表面等上下文信息。
  - 3D定位噪声可能被误判为物体移动；不同场景切换时，现有方法在构建和检索两端均会出现故障。
  - 视频语言模型直接基于帧回答问题需大量token且无法真正"离开画面后回忆"。

## 核心贡献（创新点）
1. **持久化3D物体记忆框架 LEDGER**：将几何观测与上下文描述统一存储，支持未被触碰的物体，且记录留存至物体离开视野之后。与 ConceptGraphs 等场景图方法的本质区别在于：LEDGER 以物体为中心记录运动轨迹段和描述性文本，而非仅建立空间关系图。
2. **基于重复证据的持久化分段（Persistence Segmentation）**：用"连续k次观测超出阈值τ"的规则区分真实位移与定位噪声，而非单纯增大距离阈值。与简单距离阈值方法的本质区别在于：噪声与小幅真实移动的幅度分布重叠，仅靠阈值无法分离，而持续多次观测才能确认位移。
3. **上下文描述注入每段静息段**：用 LLM 对关键帧生成短描述（容器内容、支撑面、交互信息），使记忆超越纯坐标记录。与 ReMEmbR 纯时间戳描述相比，LEDGER 的描述绑定到具体的3D静息段，保留了空间-语义联合信息。
4. **纯文本检索式问答范式**：查询时将检索结果渲染为文本，由 LLM 一次性作答，无需看到任何图像。与 DirectMe 需要读取重建图+关键帧的范式相比，LEDGER 的检索成本仅为 ~2k token/问题，约为48帧方案（~9.6k token）的五分之一。
5. **系统性消融与跨场景分析**：通过 HD-EPIC、UCS-Bench、Ego4D VQ3D 三个基准及100条拼接流的实验，分别隔离了时间持久性、上下文描述、多视角三角测量、检索方式、场景切换对性能的影响，提供了可复用的记忆设计证据。

## 方法详解
**LEDGER（Long-horizon Egocentric Descriptions, Geometry, and Event Records）** 分为离线构建和查询推理两个阶段：

**离线记忆构建（Section 3.1）**
- **检测与标记**：每4秒采样一帧（最多1200帧），用 Qwen3.5-9B 生成物体名称并通过同义词合并得到词汇表（每视频≤80标签），再用 YOLO-World 检测匹配标签的物体。
- **3D提升**：WildDet3D 从单帧图像、2D边界框和标签预测相机坐标系下的3D边界框，再结合相机位姿投影到场景坐标系。
- **关联与合并（Association & Consolidation）**：按时间顺序基于标签和3D距离将观测关联到已有实例；SAM 3 视频跟踪器传播每个片段的mask并合并mask一致的片段（IoU≥0.3，3D距离<1.0m）。
- **持久化分段（Persistence Segmentation）**：新静息段仅在连续k次观测均超出当前静息位置半径τ后才确认（HD-EPIC/UCS-Bench取τ=0.3m，k=3）。返回半径内的观测保留在当前段，抑制定位噪声导致的假位移。
- **上下文描述**：对每物体最多6个静息段，用 Qwen3.5-9B 对含物体轮廓的代表帧生成短描述（记录内容、支撑面、交互）。
- **多视角三角测量精修**：当至少3条视线的基线≥0.10m、条件数λ_min≥0.25、且估计偏移≤2.0m时，用最小二乘交汇精修3D位置（公式1）。

**查询推理（Section 3.2）**
- **定位与检索**：HD-EPIC 框查询提升至最近采样帧的3D点，检索±6s内4个最近实例；VQ3D 直接返回同名实例存储位置；UCS-Bench 按词重叠和时间邻近排序。
- **纯文本作答**：检索到的标签、排名信号、段历史（时间、位置、描述）渲染为文本，单次调用 Qwen3.5-9B 或 GPT-5.4 作答，不输入任何图像。UCS-Bench 时间戳查询时截断后续观测以保证因果性。

## 实验与结果
**数据集与评估基准**
- **HD-EPIC**：2,400道3D感知与物体运动五选一问答（原型平均准确率，随机基准20%）。
- **UCS-Bench**：2,771道带时间戳的空间推理题（随机基准25.7%）。
- **Ego4D VQ3D**：164道命名物体3D定位查询（中位误差、<1m比例）。

**主要结果**
- **HD-EPIC（Table 2）**：GPT-5.4 盲控29.7%，LEDGER+GPT-5.4 达 **42.6%**（+13.0点，p<10⁻⁸），超越所有重建基线（DirectMe 30.7%、ReMEmbR 29.8%、OSNOM 30.2%、AMEGO 34.7%）；在 Fixture Location 子类中以56.0%超越所有已发表方法。
- **UCS-Bench（Table 3）**：LEDGER纯文本38.5%（盲控33.8%，+4.7点），48帧+LEDGER达 **46.3%**（48帧 alone 44.4%），优于 DirectMe 图+48帧的42.9%。
- **VQ3D（Table 4）**：SAM 3 + 轨迹记忆 + EgoLoc位姿的中位误差 **0.99m**，<1m 比例51%，在相同协议下超越所有重建基线。

**关键消融结论**
- 持久化分段贡献最大（+5.5点），移除后运动计数精度下降15.5点；上下文描述贡献+4.9点；三角测量精修仅+2.2点（表12）。
- 定位噪声是主要伪位移来源：0.3m阈值单独使用会使计数翻倍，配合k=3后精确计数从13.5%提升至28.1%（表16）。
- 相机参考帧误差对回答影响大于物体坐标误差：重力找平使Fixture定位恢复11点（约29点损失中的一部分）（表13）。

**跨场景分析（Section E）**
- 100条拼接流（同一场景不同天 vs 不同场景）显示：返回同一场景仅损失0.5点，切换场景损失5.7点（memory-only）；按场景分别构建记忆可恢复约一半损失（+2.9~4.4点）。
- 记录长度达75分钟仍保持10-18点增益，48帧方案则随长度显著退化（表38）。

## 相关工作脉络
1. **OSNOM [36]**：追踪活跃物体的3D位置，要求物体被操作进入记忆；LEDGER 的核心差异在于接纳未被触碰的物体，这对 fixture 定位问题至关重要。
2. **ConceptGraphs [18]**：基于RGB-D建开的词汇场景图，不显式保留物体运动历史；LEDGER 以物体为中心记录静息段和时间序列。
3. **ReMEmbR [2]**：存时间戳描述+相机位置，用多轮代理检索；LEDGER 与 ReMEmbR 使用同一检索代理对比时，LEDGER 在 HD-EPIC 上胜5.0点、VQ3D <1m 胜26点，说明物体-centered 表征的结构化程度更高（表32）。
4. **DirectMe [49]**：建场景图+几何推导空间关系，需同时提供图与关键帧；LEDGER 以纯文本记录单次调用完成问答，token 成本为 DirectMe 的约1/5（HD-EPIC：1.75k vs 2.36k；UCS-Bench：2k vs 9.6k）。
5. **AMEGO [16]**：存储手-物体交互片段，适合交互计数但不存物体名和3D位置；LEDGER 在物体定位和夹具定位上显著更强，但在交互计数上 AMEGO 仍占优（HD-EPIC 47% vs 41%）。
6. **视频语言模型（VideoLLaMA 2、LongVA、Gemini 1.5）**：直接处理帧序列，无显式记忆结构；LEDGER 在 no-frame 条件下仍能提升10+点，证明结构化记忆的价值独立于更大模型容量。

## 局限性与未来方向
- **计数问题未解决**：物体关联将单对象分裂为多条track且遗漏其他对象，UCS-Bench 计数子任务在加入记忆后反而下降（表26）。
- **长时长稠密场景可扩展性有限**：HourVideo 中仅167条中21条成功构建，50-60分钟记录约4,000个实例，构建耗时74-3,500小时/条（Appendix D）。
- **多场景切换仍在破坏构建与检索**：标签规范化假设单一场景、位姿估计在场景边界处失败，虽分场景构建可部分恢复，但非根本解。
- **连续静止区间与事件边界难以精确定位**：静止段起始时间与真实停止时刻的相关性接近随机（Appendix B.8）。
- **当前为离线构建**：时间戳过滤不能证明因果在线记忆；需要全链路仅利用查询时刻之前数据的验证。
- **度量尺度依赖**：大部分 UCS-Bench 记录缺乏度量尺度，距离以场景单位表示，限制了跨场景通用性。

## 研究启发与可借鉴点
1. **持久化分段规则可直接迁移**："k次连续超阈才确认位移"的噪声抑制策略适用于任何基于轨迹的时序分割任务，避免了简单距离阈值在噪声与真实移动幅度重叠时的失效。
2. **上下文描述+几何的联合表征设计值得借鉴**：将 LLM 生成描述绑定到具体3D静息段而非全局 caption，使空间记忆同时具备语义丰富性和几何精确性，可作为多模态记忆压缩的通用范式。
3. **检索器-记忆对比实验设计**：论文用同一检索代理（ReMEmbR agent）公平比较不同记忆结构（表32），此设计可复用于评估其他记忆系统的表征质量，避免"好记忆配好读者"的归因偏差。
4. **跨场景分割策略的工程启发**：CLIP嵌入无重访检测（r₁₀≥1）的场景切割方法（Appendix E.4）对多场景首人称视频的记忆管理具有直接参考价值；按场景分别构建记忆的思路可推广至任何长时记忆系统。
5. **token效率与性能的权衡分析**：论文量化了记忆纯文本方案（~2k token） vs 48帧（~9.6k token）的成本-收益比（Appendix H），为在线部署决策提供了清晰的参考框架。

## 关键术语表
- **LEDGER**：Long-horizon Egocentric Descriptions, Geometry, and Event Records，论文提出的持久化3D物体记忆系统。
- **Persistence Segmentation（持久化分段）**：要求连续k次观测均超出当前静息半径τ才确认新段，以抑制定位噪声引起的假位移检测。
- **Rest Segment（静息段）**：同一物体在同一 resting location 的所有观测聚合为一个时段段，记录时间跨度、3D位置和上下文描述。
- **Trajectory Memory vs Raw Memory**：轨迹记忆按时间顺序关联观测（保留多实例同名物体），原始记忆按标签全局聚类（只返回一个中心位置）。
- **Consolidation（合并）**：第二阶段后处理，用 SAM 3 mask 传播和共现检查合并可能属于同一物体的多个fragment track。
- **Triangulation（三角测量精修）**：利用至少3条来自不同相机位置的视线交汇估计更精确的3D点。
- **Scene Cut（场景切换）**：视频流中不同物理场景的边界，会导致记忆构建和检索同时失效。
- **Blind Control（盲控）**：仅向模型提供问题和选项、不提供任何记忆或帧的条件，作为零样本基线。
