# 论文速读：SAREO-FM: DECOUPLED SEMANTIC SUPERVISION FOR SAR-EO FOUNDATION MODELS

## 一句话总结
本文提出 SAREO-FM，一种面向合成孔径雷达（SAR）与光电磁（EO）影像的统一基础模型。通过将高层语义对齐目标解耦至可学习语义查询流，而将底层像素重建目标保留给模态特定 token 流，该设计在共享编码器内实现了跨模态语义聚合与模态特征保真的并行优化，在 S AR、EO 及联合输入下均取得强迁移性能。

## 研究问题与动机
1. SAR 与 EO 成像机理迥异（微波后向散射 vs. 光谱纹理外观），如何在一个统一框架中同时学习模态特定的低层细节与跨模态通用的高层语义，是构建实用地理空间基础模型的核心难点。
2. 现有 MAE 类方法（如 SARMAE）通常直接将 SAR/EO 图像 token 与 VFM 提取的教师特征对齐，导致同一 token 流被迫同时满足像素重建与高层语义匹配，产生表征优化冲突。
3. 缺乏将“语义监督目的地”与“重建监督目的地”显式分离的机制，限制了共享编码器在多模态互补场景下的表征纯度与下游泛化能力。
4. 真实遥感场景中常存在模态缺失或配对不全，预训练阶段需要一种能灵活暴露编码器于 SAR-only、EO-only 及联合 SAR-EO 输入的采样策略。

## 核心贡献（创新点）
1. **提出 SAREO-FM 统一预训练框架**：基于 MAE 架构联合建模 SAR 与 EO 原始影像，支持 SAR-only、EO-only 与联合 SAR-EO 的无缝下游迁移。与仅把 EO 当作教师信号的工作不同，本文首次将原始 EO 作为独立学生模态参与联合重建。
2. **设计解耦语义监督（Decoupled Semantic Supervision）**：将冻结 VFM 的语义对齐目标专供空间对齐的可学习查询流，而将掩码像素重建目标严格限定于 SAR/EO 图像 token 流，从监督目标层面根除单一 token 的多重优化冲突。
3. **开发混合模态掩码策略**：组合独立掩码、空间共享掩码、完整 EO 丢弃与完整 SAR 丢弃四种采样模式（概率 0.35/0.35/0.15/0.15），使编码器在预训练期充分接触配对与单模态分布，提升缺失模态鲁棒性。
4. **百万尺度实证验证与严格对照实验**：在 SAR-1M（131 万张图像）上完成预训练，并以严格控制变量方式的 SARMAE* 为基线，系统证明了解耦查询监督与原始 EO 联合建模的累积增益。

## 方法详解
1. **三流统一编码结构**：输入划分为 SAR 图像 token、EO 图像 token 与 N=256 个空间对齐的可学习语义查询。各类 token 分别叠加模态专属嵌入（SAR/EO/Query）与共享 2D 正弦余弦位置编码后，拼接输入共享 ViT-B/16 编码器，经多层自注意力交互得到 `Z_s`、`Z_e` 与 `Z_q`。语义查询在所有阶段永不掩码。
2. **解耦语义对齐损失**：冻结的 DINOv3-7B 教师模型处理干净未掩码的 EO 图像，提取最终层 patch 特征 `T`。若教师分辨率不匹配则双线性重采样至 16×16 网格。查询输出 `Z_q` 经两层 MLP 投影后，与教师特征逐 patch 计算余弦距离：
   `L_align = (1/N) Σ_i (1 - cos(h_φ(z_q^i), t^i))`
   图像 token 不直接受此损失约束，从而保持对模态特定几何与回波特征的保留能力。
3. **模态特异性掩码重建**：语义查询输出 `Z_q` 被显式排除在重建分支之外。SAR 与 EO 的可见 token 分别送入独立解码器 `D_s`、`D_e`，在掩码位置插入可学习 mask token，恢复原始 patch 并计算 L1 像素损失 `L_pix^s` 与 `L_pix^e`。
4. **混合模态掩码采样**：训练时按概率抽取四种模式：
   - 独立掩码（0.35）：两模态掩码位置独立，鼓励细粒度跨模态局部补全；
   - 共享掩码（0.35）：两模态同位置同时隐藏，迫使模型依赖全局上下文推理；
   - 完整 EO 丢弃（0.15）：仅保留 SAR 输入，训练纯 SAR 语义聚合；
   - 完整 SAR 丢弃（0.15）：仅保留 EO 输入，训练纯 EO 语义聚合。
   每个保留模态内部均按 75% 比例随机掩码 patch。
5. **预训练目标**：`L = λ_s L_pix^s + λ_e L_pix^e + λ_align L_align`，系数设为 `λ_s=1, λ_e=1, λ_align=0.5`。丢失项按当前采样模式动态置零。
6. **下游迁移协议**：推理时丢弃 VFM 教师、语义投影器与重建解码器。编码器接收所有可见 patch 与全部 256 个查询，下游头可灵活选用：仅模态 token 池化（`mod`）、仅查询输出池化（`sem`）或两者拼接（`both`），适配识别、检测或密集预测等不同任务需求。

## 实验与结果
1. **数据集与设置**：预训练语料为 SAR-1M（1,312,902 张 SAR 图像，含 1,042,156 对配准 EO）。下游涵盖 S AR 目标识别（MSTAR、FUSAR-Ship、SAR-ACD）、EO 场景分类（EuroSAT、NWPU-RESISC45、AID）、配对 SAR-EO 识别（So2Sat LCZ42、BigEarthNet-MM）及 BRIGHT 密集预测定性
