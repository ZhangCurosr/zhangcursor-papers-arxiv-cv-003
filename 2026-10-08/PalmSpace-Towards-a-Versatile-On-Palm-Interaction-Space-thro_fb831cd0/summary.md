# 论文速读：PalmSpace-Towards-a-Versatile-On-Palm-Interaction-Space-through-Unified-Touch-Modeling

## 一句话总结
PalmSpace 提出一种佩戴于手腕的红外视觉系统，通过将触摸状态检测、交互模式识别与手掌绝对坐标定位统一到单一的多任务 Transformer 模型中，使裸露的手掌成为一个无需逐用户校准、具备模式感知的通用交互表面。

## 研究问题与动机
- 智能眼镜/轻量 MR 设备在移动场景下缺乏既精确又随时可用、且支持无视觉注意的输入方式。
- 现有手掌交互系统多暴露孤立的离散区域、独立触摸事件或单一轨迹，缺乏同时表达“是否存在接触、接触位置、交互模式”的统一表示，导致手掌只能被当作稀疏事件集合，难以支撑复杂操作（如地图缩放旋转）。
- 多数可穿戴方案依赖外部深度相机/投影仪等 bulky 硬件、手指贴片传感器或需要逐用户校准，难以在轻量头戴设备上实用部署。
- 现有系统通常仅覆盖接触检测、定位或特定手势中的一项，未能在紧凑腕戴形式下同时实现跨用户的免校准绝对定位与多指模式识别。

## 核心贡献（创新点）
1. **统一的交互表示框架**：提出同时编码接触存在、交互模式与手掌参照绝对位置的共同表示，将手掌结构化为主题感知的交互空间，而非孤立触摸事件集合。
2. **免校准的跨用户手势感知模型**：设计多任务 Transformer，以共享表征联合预测四分类交互状态与归一化 2D 坐标，相比独立训练的分类/定位模型在零样本户外数据上提升定位精度与触摸识别率，且仅需部署一个模型。
3. **手掌归一化坐标系统**：以腕中线与掌根为参考、以掌宽/掌长为归一化因子，将不同受试者的手型差异映射到固定范围，显著改善跨用户泛化能力并免去逐人传感校准。
4. **紧凑腕戴红外传感原型与系统工作流**：集成翻折结构 IR 相机与主动照明，支持三种单指姿态与滚动/捏合多指模式，并在离线 LOPO 评测与多项室内/户外用户研究中验证了指向、盲打、书写与地图操控等能力。
5. **全面的离线与在线评估体系**：提供多维度误差分析、消融实验（归一化、数据增强、架构对比）及零样本户外鲁棒性评测，并展示 SUS 可用性反馈与设计空间讨论。

## 方法详解
- **交互表示**：定义四种交互状态——Non-contact、Single-finger、Scroll、Pinch，其中前三者隐含单指/多指模式，Contact 语义由状态区分；回归目标为归一化 2D 接触点坐标。
- **手掌归一化坐标**：横向坐标以腕中线为原点、除以掌宽映射到 [−0.5, 0.5]；纵向坐标以掌根为基准、除以掌长映射到 [0, 1]，从而将几何变化解耦，提高跨用户一致性。
- **网络架构**：ViT-B/16 骨干提取特征后，经 1×1 卷积投影至 $d_{model}=256$ 维度并加入二维正弦位置编码；随后进入含 3 层编码器的轻量 Transformer，prepend 可学习 class token $t_{cls}$ 作为共享隐表示；上方并联两个两层 MLP 头，分别执行四分类与坐标回归。
- **训练目标**：总损失 $\mathcal{L}_{total} = \lambda_{cls}\mathcal{L}_{cls} + \lambda_{reg}\mathcal{L}_{reg}$，其中 $\mathcal{L}_{cls}$ 为标准交叉熵；$\mathcal{L}_{reg}$ 为掩码 MSE，掩码 $M_i = \Psi(y_i \neq \text{Non-contact})$ 排除无接触样本；实验取 $\lambda_{cls}=1, \lambda_{reg}=100$ 以平衡数值尺度。
- **多指代理设计**：对 Scroll/Pinch，回归食指作为主交互点以代表位移矢量（Scroll）或相对中心极坐标（Pinch），从而简化同时处理多点接触的建模复杂度。

## 实验与结果
- **数据集与评测协议**：17 名右利手受试者（手长 155–200 mm，掌宽 65–85 mm），共 63,903 帧；采用 leave-one-participant-out（LOPO）交叉验证；ground truth 由俯视 4K 相机 + AprilTag 平面标定 + MediaPipe 指尖关键点生成。
- **核心指标（离线 LOPO）**：二元接触检测准确率 98.9%；四分类 F1 为 96.7%（Non-Touch 97.9%、Single 97.2%、Scroll 88.1%、Pinch 97.4%）；总体 MAE 6.7 mm（Single 6.1 mm、Scroll 6.3 mm、Pinch 10.6 mm）。
- **消融结论**：去除手掌归一化使总 MAE 升至 6.9 mm、多指误差由 8.3 mm 升至 8.8 mm；去除数据增强使 Gesture F1 由 96.7% 降至 95.3%；与独立训练的分类/定位双模型相比，统一学习在零样本户外数据上将 MAE 从 11.7 mm 降至 9.6 mm、Touch F1 从 93.0% 提升至 95.7%。
- **用户研究（室内/户外）**：Fitts 定律实验中 PalmSpace 总耗时 1572.2 ms（触屏 1361.6 ms），拖拽时间无显著差异；盲打数字输入准确率达 93.71%，显著优于触屏的 74.86%（p<0.01）；户外日间零样本 MAE 9.6 mm，微调后 6.8 mm，F1 98.7%；夜间 Fitts 任务用时 1509.03 ms，与室内相近。
- **最强结果**：LOPO 总体 MAE 6.7 mm、接触准确率 98.9%、四类 F1 96.7%；户外零样本对比独立双模型定位误差降低约 18%（11.7→9.6 mm）。

## 相关工作脉络
- **PalmRC / PalmType**：基于深度相机/离散红外传感器，提供离散区域或特定按键式输入，无法连续绝对定位，且多数依赖固定姿态或标定。
- **PalmGesture**：引入红外相机与激光线实现连续输入，但需用户四点标定交互区域并对手指俯仰角施加严格约束。
- **SkinTrack / TouchCam / HandPad**：分别采用 RF、指端佩戴传感器与腕+指贴片，虽精度可观但引入额外硬件或需用户校准，便携性受限。
- **EgoTouch / Palmpad**：利用头显 RGB 相机进行主视角触摸检测，属 viewpoints 依赖方案，易受自遮挡与视角限制影响，且在表 1 中不支持多指模式与绝对坐标。
- **LumiWatch / OmniTouch**：借助投影与深度相机实现体感触控，精度高但系统 bulky，难以适配轻量 MR/智能眼镜形态。
- **定位差异**：PalmSpace 在紧凑腕戴架构下同时实现免校准绝对定位、多指模式识别与眼睛免注视，填补了以往系统仅在单一维度上突破的空白。

## 局限性与未来方向
- 数据集受限于 17 名受试者与相对单一的采集条件，尚未系统覆盖配饰、指甲形态、不同肤色与更广泛的手指特有行为等真实变异性。
- 多指交互目前采用以食指为代理的单点连续映射，难以直接扩展到更细粒度、更密集的多指形变与多触点独立追踪场景。
- 原型为有线连接，尚未完成无线化与嵌入式低功耗部署；尽管 INT8 量化与 TorchScript 已带来 3.7× 体积压缩与 2.7× 加速，仍需持续探索面向更低功耗平台的模型压缩与系统级优化。
- 未来可扩展更丰富的多指手势语义、融合触觉/力觉反馈，并在真实 AR/MR 终端中进行长期野外部署评估。

## 研究启发与可借鉴点
- **统一多任务表示策略**：将接触检测、模式分类与坐标回归并入共享 Transformer 表征，既减少部署复杂度又提升跨分布泛化，可迁移至其他多模态/多任务体感交互系统。
- **形态归一化的坐标范式**：以人体解剖学基准结合尺寸归一化将绝对像素/物理坐标转为比例空间，是解决跨用户尺寸差异的有效且可复用的设计，适用于任意体表交互面。
- **离线 LOPO + 在线零样本/微调的评估链路**：兼顾跨用户鲁棒性与真实户外域偏移的评测流程值得在可穿戴视觉交互研究中推广。
- **单点代理多指映射的工程设计**：以食指位移/相对中心极坐标分别驱动 Scroll 与 Pinch，可在保持控制精度的同时大幅简化多指建模复杂度，可作为轻量 MR 输入设计的参考模板。

## 关键术语表
**PalmSpace**：一种腕戴红外视觉系统，将裸露手掌转化为具备接触感知、绝对定位与模式识别能力的交互空间。
**交互状态（Interaction State）**：四类离散语义标签（Non-contact、Single-finger、Scroll、Pinch），联合编码是否接触及单/多指模式。
**手掌归一化坐标**：以腕中线/掌根为参考、以掌宽/掌长归一化的相对坐标系，实现跨用户一致的绝对定位。
**多任务 Transformer**：基于 ViT-B/16 与轻量 3 层 Transformer 骨干，通过共享 class token 同时预测类别与连续坐标的架构。
**LOPO 交叉验证**：Leave-One-Participant-Out 策略，逐轮留出一名受试者作测试集，用于评估模型的跨用户泛化性。
**Fitts 定律**：描述指向目标时间与目标距离、大小之间关系的经验定律，常用于衡量指向/拖拽交互效率。
**掩码 MSE 回归损失**：仅在有效接触样本上计算均方误差的回归损失，排除 Non-contact 样本以避免无效梯度。
**SUS（System Usability Scale）**：10 项问卷构成的主观可用性量表，本文测得平均分 72.5，属“Good"等级。
