# 论文速读：VISIONWEAVE-WEAVING-ELASTIC-VISUAL-REPRE-SENTATIONS-AS-A-NAT

## 一句话总结
本文提出 VisionWeave，通过在 MLLM 中内化一种“弹性视觉表征编织”的原生能力，模型能根据视觉内容的信息密度自适应地在细粒度（高质量）与粗粒度（高效率）表征间切换。该方法仅通过三阶段自蒸馏训练实现，在 Qwen3.8-27B 上平均节省 43.0% 的视觉 token 的同时，仅造成 1.08% 的性能损失，并在 SGLang 推理引擎上实现了 2.30 倍的端到端吞吐量提升。

## 研究问题与动机
1.  **核心问题**：现代多模态大语言模型（MLLMs）在处理高分辨率图像和长视频时，因视觉输入被划分为固定大小的 patch 并编码为密集的视觉 token 序列，导致计算和内存开销巨大。视觉信息分布不均，如何在不显著损失质量的前提下自适应地减少视觉 token？
2.  **现有方法不足 - 下采样**：简单的图像下采样会牺牲细粒度细节，无法满足需要精细空间理解的视觉问答、文档分析和 GUI 定位等任务。
3.  **现有方法不足 - Token 剪枝/合并**：FastV、VisionZip 等剪枝和合并方法存在训练-推理不匹配的问题，且常依赖注意力权重等难以与现代推理引擎（如 SGLang, vLLM）集成的机制。此外，它们通常使用预设的压缩率，缺乏对输入内容自适应的粒度调整能力。
4.  **现有方法不足 - 自适应分辨率**：ViCO 等方法虽尝试自适应分配分辨率，但其基于 tile 的设计限制了其在采用原生分辨率视觉处理的现代 MLLM（如 Qwen, Kimi）中的直接应用，且粒度划分粒度较粗。

## 核心贡献（创新点）
1.  **提出“弹性视觉表征编织”的原生能力**：本文是首个通过大规模训练，将弹性视觉表征编织作为 MLLM 原生能力确立的工作，使模型能自主决定何处保留细粒度细节、何处使用紧凑表征。
2.  **门控空间池化器（Gated Spatial Pooler）**：在共享的 MRoPE 坐标框架内，与原生细粒度 token 并行构建学习到的粗粒度表征。该池化器是可学习的均值池化扩展，通过门控机制聚合相邻 patch 特征，输出语义充实的压缩表征。
3.  **粒度路由器（Granularity Router）**：通过探测 ViT 多层特征，学习为每个空间块内容自适应地分配细粒度或粗粒度表征，实现基于内容而非固定预算的 token 节省。
4.  **仅通过三阶段自蒸馏进行训练**：提出了一个渐进式的自蒸馏训练流程（粗粒度蒸馏 -> 软混合蒸馏 -> 硬路由蒸馏），无需额外标注数据，仅利用原生模型自身作为教师，便将弹性视觉处理能力内化。
5.  **与现代推理基础设施深度集成并验证实际收益**：将 VisionWeave 集成到 SGLang 推理引擎，支持半整数坐标的 MRoPE 和混合粒度序列，证明了其从算法效率到实际部署吞吐量和延迟改善的全链路价值。

## 方法详解
方法由两个核心组件和三阶段训练组成。
*   **架构设计**：
    *   **门控空间池化器**：将 ViT 输出的每个 $2 \times 2$ patch 邻域特征进行归一化，计算共享全局上下文 $g_k$，然后通过门控机制（基于特征 $u_k$ 和上下文 $g_k$ 的 channel-wise softmax）计算权重 $\alpha_k$，最终加权求和得到池化特征。该操作将 $4 \times 4$ 个 patch 压缩为 1 个粗粒度 token，并通过位置插值将其放置在对应 fine-grained tokens 的几何中心。
    *   **粒度路由器**：为每个空间块初始化一个可学习查询 $h_{IJ}$，该查询在 ViT 的三个深度层（浅层、中层、深层）上依次进行局部和全局交叉注意力操作，以融合低层细节和高层语义。最终通过线性头输出使用粗粒度表征的概率 $p_{IJ}$。若 $p_{IJ} > t$（默认阈值 0.5），则选择粗粒度 token，否则保留四个细粒度 token。
*   **三阶段自蒸馏训练**：
    1.  **阶段一（粗粒度自蒸馏）**：冻结 LLM 和 ViT，仅训练门控空间池化器。对所有空间块 bypass 路由，强制使用粗粒度表征 $V_{student} = flatten(V_{coarse})$，通过 KL 散度对齐原生教师模型的输出分布。
    2.  **阶段二（软混合自蒸馏）**：冻结池化器和 LLM/ViT，仅训练粒度路由器。使用可微的软混合表征 $V_{mix}$ 作为学生输入，结合了细粒度和粗粒度的方向与幅度。引入平衡损失 $\mathcal{L}_{bal}$ 鼓励路由器达到目标粗粒度路由比例 $\rho=0.8$。
    3.  **阶段三（混合粒度自蒸馏）**：解冻池化器和 LLM（冻结 ViT、原生合并器和路由器），对推理时使用的硬路由混合粒度序列 $V_{student}$ 进行自蒸馏。此阶段通过校准路由器头部的偏差，使学生模型适应最终的离散路由决策。
*   **推理**：单个 ViT 前向传播同时获得细粒度和粗粒度 token，路由器根据概率阈值 $t$ 进行硬选择，将混合粒度的 token 序列送入 LLM 进行生成。

## 实验与结果
*   **数据集与基线**：在 8 个涵盖自然图像、文档、GUI 定位、幻觉检测和视频理解的基准上进行评估。主要基线为 FastV†（修改后于视觉编码器后剪枝）和 VisionZip。
*   **主要结果（Qwen3.8-27B, 512 tokens/image）**：
    *   **质量与效率权衡**：VisionWeave 平均节省 **43.0%** 的 token，仅造成 **1.08%** 的平均性能损失（从 77.65 降至 76.73）。相比之下，固定节省 50% 目标的 FastV† 和 VisionZip 性能损失分别高达 **11.82%** 和 **12.46%**。
    *   **复杂任务优势**：在信息密集的任务上优势显著。例如在 ScreenSpotV2 上，VisionWeave 在节省 55.1% token 的情况下仅损失 3.17 分，而 FastV† 在节省约 50% token 时损失高达 47.54 分。
    *   **鲁棒性**：在不同图像分辨率和视频帧预算 sweeps 中，VisionWeave 始终比输入下采样提供更优的效率-质量权衡曲线。
    *   **推理控制**：默认阈值 $t=0.5$ 已能自适应节省；通过调整 $t$ 可在不重新训练的情况下灵活控制节省率与性能的平衡。
*   **SGLang 部署性能**：
    *   端到端吞吐量提升 **2.30 倍**（从 0.90 增至 2.07 req/min）。
    *   平均首次 token 生成时间（TTFT）降低 **54.4%**。
    *   平均每输出 token 处理时间（TPOT）降低 **60.6%**。
*   **消融实验**：
    *   门控空间池化器显著优于 pixel-unshuffle 基线。
    *   学习到的粒度路由比随机打乱的 routing 重要得多（在 Qwen3.8-27B 上平均性能下降 5.36 分）。
    *   第三阶段的硬路由蒸馏对最终性能提升关键，尤其在 ScreenSpotV2 上带来 24.84 分的提升。

## 相关工作脉络
1.  **Visual Token Pruning/Merging (FastV, VisionZip)**：这些方法通过启发式或学习到的策略直接丢弃或合并视觉 token。VisionWeave 与之的本质区别在于，它不是“丢弃”信息，而是“替换”为另一种等价的、更紧凑的表征形式，从而保持空间覆盖的完整性，避免了关键信息的永久丢失。
2.  **Adaptive Patch Sizes / Resolution (ViCO)**：ViCO 为每个图像 tile 自适应分配分辨率。VisionWeave 与之的区别在于：其一，直接在 MLLM 的原生分辨率流水线内工作，无需 tile 分割；其二，在比 tile 更细的 spatial block 粒度上进行决策，能更好地处理细节丰富区域与低信息背景交错的情况。
3.  **KV-cache Compression**：如 DeepSeek-V4 等通过压缩 attention 中的 KV 状态来节省内存。VisionWeave 作用于输入序列长度层面，减少的是进入 LLM 的 token 数量，从而同时降低 prefill 的计算和 KV-cache 内存，二者是正交且可结合的方向。
4.  **Post-training Efficiency Methods for MLLMs**：许多效率方法是在预训练完成后添加的模块或策略。VisionWeave 强调通过自蒸馏将弹性处理能力“内化”为模型的原生能力，使其成为模型基础架构的一部分，而非外挂组件。

## 局限性与未来方向
1.  **计算成本限制探索**：训练过程需要超过 30K 个 A100 GPU 小时，这限制了对更多架构变体（如不同的路由器设计）的全面探索。
2.  **粒度数量**：当前仅探索了两种粒度（细/粗）。未来可以向更丰富的多尺度表示扩展，以捕捉更精细的信息层次。
3.  **训练阶段**：目前该方法通过后训练自蒸馏植入。未来可以探索在基础模型预训练阶段就引入弹性视觉编织，可能获得更强大的原生能力。
4.  **路由器的复杂性**：当前的路由器设计（多层交叉注意力）有一定开销，如何在保证性能的同时进一步简化路由器架构是一个潜在方向。

## 研究启发与可借鉴点
1.  **三阶段渐进式自蒸馏策略**：这种从“全粗粒度”到“软混合”再到“硬路由”的训练范式，为将新的、离散的选择机制平滑地嵌入预训练模型提供了一个可靠且高效的模板，可迁移至其他需要离散决策的模型能力学习中。
2.  **“替换”优于“丢弃”的表征思维**：在需要保持空间结构完整性的任务（如 grounding、OCR）中，用等价的紧凑表征替换原始 token，比直接删除 token 更能保持性能。这一思想可应用于其他需要维持空间或结构信息的模态处理任务。
3.  **与推理引擎的深度协同设计**：论文不仅提出了算法，还主动适配了 SGLang 的 RoPE 缓存和序列调度机制。这种从算法设计初期就考虑端到端部署可行性的思路，对于追求实际落地效率的研究具有重要示范意义。
4.  **内化效率为原生能力**：将效率机制（如动态计算、稀疏激活）通过蒸馏等方式转变为模型的内生属性，而非外部后处理步骤，可以使模型在各种下游场景和未知输入中自动发挥效率优势，这是设计下一代高效基础模型的一个有力方向。

## 关键术语表
*   **Elastic Visual Representation Weaving**: 指模型根据输入视觉内容的信息密度，自适应地编织（混合使用）细粒度和粗粒度视觉表征的能力。
*   **Gated Spatial Pooler**: VisionWeave 的核心组件之一，通过学习门控权重将 $2 \times 2$ 的 patch 邻域特征聚合为一个粗粒度 token，输出与细粒度 token 处于同一嵌入空间。
*   **Granularity Router**: VisionWeave 的另一核心组件，一个基于交叉注意力的小型网络，为每个图像空间块输出选择细粒度或粗粒度表征的概率。
*   **MRoPE (Multimodal Rope)**: 多模态旋转位置编码，为视觉 token 和文本 token 赋予时空坐标，VisionWeave 中粗粒度 token 通过位置插值被放置在对应细粒度 token 的几何中心。
*   **Self-Distillation**: 在本工作中指使用原生（未修改的）大模型作为教师，指导经过修改（引入了池化器和路由器）的学生模型进行训练的过程。
*   **Soft-Mixing Surrogate**: 训练阶段二中使用的一种可微分的替代方案，通过对细粒度和粗粒度 token 的特征方向和范数进行加权插值，来模拟硬路由的选择过程，以便于梯度反向传播。

## 可复现要素
*   **数据集**：训练数据为 LLaVA-OneVision (246K), LLaVA-Video-178K (281K), UGround (250K) 的混合物。基准测试集均为公开标准数据集（Real-WorldQA, DocVQA, InfoVQA, ScreenSpotV2, HallusionBench, VideoOCR, Video-MME, LongVideoBench）。
*   **代码与权重**：论文声明 SGLang 集成代码及其他细节将在 https://github.com/FFY0/VisionWeave 开源。使用的基础模型为 Qwen3.5-4B 和 Qwen3.8-27B（需从官方渠道获取）。
*   **关键超参数**：路由阈值 $t=0.5$（默认）；软混合阶段的目标粗粒度比例 $\rho=0.8$；各阶段学习率分别为 $1e-4$, $1e-5$, $3e-6$；蒸馏温度 1；ViT 特征探测深度为 [0, 13, 27]。
