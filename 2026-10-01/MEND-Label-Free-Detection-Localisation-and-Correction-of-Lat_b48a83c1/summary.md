# 论文速读：MEND-Label-Free-Detection-Localisation-and-Correction-of-Lat

## 一句话总结
本文针对冻结自监督世界模型中潜空间的“幻觉”现象，提出 MEND 方法，仅需真实状态转移数据训练一个条件得分网络，即可在无标签情况下同步完成幻觉检测、图像块级定位与推理时修正，并在 WALL 与 POINTMAZE 导航环境中显著提升预测可靠性。

## 研究问题与动机
- 世界模型在潜空间进行自回归预测时，可能输出数值统计合理但解码后对应不可能场景的“潜幻觉”，且误差会随 rollout 深度累积放大。
- 现有评估主要关注下游规划成功率或奖励，缺乏对想象轨迹本身偏离真实动态的主动检测与纠正机制。
- 幻觉误差在空间上高度稀疏（少量 token 携带绝大部分误差），但现有方法无法在无需真实误差标签的情况下精确定位并修复这些 token。
- 收集失败样本重新训练成本高昂，亟需一种作用于冻结模型、推理时即插即用的无标签应对方案。

## 核心贡献（创新点）
1. **首次定义并分类潜世界模型的幻觉**：提出不可达状态型（S）与错误动作结果型（A）两类幻觉，并实证误差在 token 级高度稀疏。与以往聚焦显式像素或语言输出幻觉的工作不同，本文聚焦冻结自监督潜空间的动态不一致性。
2. **统一“检测-定位-修正”循环框架**：证明单个可微得分函数可同时承担全局置信度评分、逐 token 归因与修正梯度输出，避免多模块拼接带来的复杂度与误差传播。
3. **提出 MEND 无标签实例化**：通过去噪分数匹配在真实转移上训练条件得分网络，并利用 Tweedie 公式将得分场直接转化为指向合法流形的修正方向，完全摆脱对世界模型预测分布与幻觉标签的依赖。
4. **跨环境鲁棒验证**：在 DINO-WM 冻结背骨的两个导航环境中，检测 AUROC 最高达 0.801，定位 per-token AUPRC 最高达 0.874，单步修正即可降低潜误差并改善近 99% 预测，展示强可复现性。

## 方法详解
- **通用循环结构**：输入当前潜状态 $z_t$ 与动作 $a_t$，预测 $\hat{z}_{t+1}$ 后送入统一可微得分网络 $s_\theta$。网络输出标量检测分、逐 token 定位图与修正方向，迭代执行 mask 约束下的 Tweedie 位移直至 $\tilde{\mathcal{D}} < \tau$、步长低于 $\delta$ 或达到预算 $K$。
- **贝叶斯分解与因子化检测**：将 $p(\hat{z}_{t+1}|z_t,a_t)$ 分解为可达性项 $p(\hat{z}_{t+1}|z_t)$（D1）与动作一致性项 $p(a_t|z_t,\hat{z}_{t+1})$（D2）。本文主体采用 D1，D2 通过逆动力学残差近似；消融表明在确定性环境中 D2 判别力接近随机，D1 已足够。
- **条件得分网络训练**：对真实转移 $(z_t, z_{t+1})$ 添加高斯噪声 $\tilde{z}=z_{t+1}+\sigma\varepsilon$，以去噪分数匹配最小化：
  $\mathcal{L}(\theta) = \mathbb{E}[\sigma^2 \|s_\theta(z_{t+1}+\sigma\varepsilon|z_t,\sigma) + \varepsilon/\sigma\|^2]$。
  训练目标为 $\sigma$-平滑合法状态分布的条件得分 $\nabla \log q_\sigma(\tilde{z}|z_t)$，网络完全不接触世界模型预测样本。
- **一域三用机制**：
  - **检测**：标量 $\mathcal{D} = \|s_\theta(\hat{z}_{t+1}|z_t)\|^2$，经校准后标准化为 $\tilde{\mathcal{D}}=(\mathcal{D}-\mu_{\mathrm{acc}})/\sigma_{\mathrm{acc}}$。
  - **定位**：逐 token 范数 $\|s_\theta(\cdot)_n\|$ 直接度量该 token 偏离流形的程度，无需额外反传。
  - **修正**：由 Tweedie 公式得位移 $d=\sigma^2 s_\theta$。算法第一步冻结 top-p% 最可疑 token 的支撑集 $S$，后续迭代执行 $z \leftarrow z + \eta(m \odot d - \rho(z-\hat{z}_{\mathrm{orig}}))$，保持可信 token 基本不动。
- **部署超参**：检测用 $\sigma=0.39$ 捕获全局结构；修正用 $\sigma=0.05$、步长 $\eta=0.3$、锚点权重 $\rho=0.1$、最大迭代 $K=10$；支持集比例 $p\%$ 在第一步固定后全程不变。

## 实验与结果
- **环境/骨干**：冻结 DINO-WM（DINOv2 ViT-S/14，196 tokens，384 维），在 WALL（单帧历史）与 POINTMAZE（三帧历史）两个导航环境测试。
- **基线**：单对角高斯密度拟合 [15]、逆动力学检测器、直接 AdaLN 动作条件变体、交叉注意力动作注入变体。
- **检测性能**：WALL 上 MEND 检测 AUROC 达 **0.801**，显著超越高斯基线 0.648；POINTMAZE 达 **0.691** 优于基线 0.631。检测对标注阈值鲁棒，数百条轨迹即饱和。
