# 论文速读：What Remains Normal? Clean Images Miss Useful Near-Defect Normal Patches for Anomaly Detection

## 一句话总结
论文通过固定预算诊断发现，仅用干净训练图像构建的异常检测器会遗漏缺陷图像中紧邻缺陷的正常补丁特征；为此提出 **BOUNDARYSUPPORT**，通过在干净图像上施加合成缺陷以改变周围上下文、排除受影响的 token、仅利用像素保留的邻域特征作为额外参考或重建目标，在 MVTec AD、VisA 和 Real-IAD 上稳定提升了像素级定位性能。

## 研究问题与动机
- **核心假设存疑**：工业异常检测主流方法假设"干净训练补丁足以覆盖测试时的正常区域"，但基于上下文的编码器（如 DINOv2）使密集特征依赖于周围内容，缺陷图像中紧邻缺陷的正常补丁可能处于干净图像从未出现的上下文状态。
- **干净池也可能不完整**：现有处理污染训练数据的方法（如 SoftPatch、FUN-AD）聚焦于"去除不可靠内容"，但未解决"干净池中可能缺失有用特征"的问题。
- **诊断证据直接**：在 MVTec AD 上将真实缺陷图像的 GT-标记正常补丁纳入候选池（保持编码器、打分规则、存储数量不变），P-AP 从 73.34 提升至 76.95（+3.62 点），其中距缺陷两格范围内的补丁恢复了 94.70% 的增益，说明缺失特征集中在缺陷邻域。
- **脱离对真实缺陷标注的依赖**：上述诊断使用了真实缺陷掩码，实际部署不可行；因此需要一种仅在干净训练图像上即可暴露此类有用特征的干预机制。

## 核心贡献（创新点）
1. **固定预算诊断揭示干净池的缺陷邻域缺失问题**：通过控制候选集身份而冻结其余所有组件，证明添加真实缺陷图像中的 GT-正常补丁可在相同预算下显著提升 P-AP；已有工作未以同等控制方式量化干净训练的表征覆盖缺口。
2. **BOUNDARYSUPPORT——纯干净训练干预框架**：通过过程合成缺陷改变周围上下文，显式排除被修改的 token（含名义插入区与实测 RGB 变化区），仅将像素保留的邻域特征用作额外参考/重建目标；与现有合成异常方法（如 CutPaste、NSA）以合成核心作为异常监督的定位截然不同。
3. **跨范式的匹配对照实验锁定有用特征来源**：在重建分支中固定合成输入与环位置仅替换目标，或在记忆分支中固定选定位置与银行预算仅替换存储特征，证明"改变上下文后的特征"均显著优于其干净视图对应物（MVTec 重建差距达 +12.07 点），排除了空间选址或合成曝光本身的混淆。
4. **空间分布一致性验证**：最终检测器的分数变化在缺陷邻域正常补丁上最强（MVTec 近-远差值中位数为 -0.51），与诊断发现的地理集中性一致，建立了从训练干预到推理行为的空间对应。

## 方法详解
**诊断阶段（固定预算 GT-正常 oracle）**：
- 定义干净候选池 $\mathcal{Z}_{\text{clean}}$ 与真实缺陷 GT-正常补丁池 $\mathcal{Z}_{\text{def},N}$；在相同 bank 大小 $B$ 下构建 $M_B^{\text{clean}} = \text{KCenter}_B(\mathcal{Z}_{\text{clean}})$ 与 $M_B^{\text{oracle}} = \text{KCenter}_B(\mathcal{Z}_{\text{clean}} \cup \mathcal{Z}_{\text{def},N})$，编码器与打分规则完全冻结，证明候选身份本身是 P-AP 提升的主因。
- 按与缺陷单元格距离分层：$0 < d \leq 2$ 的近缺陷补丁恢复 94.70% 增益（76.76 P-AP），近>中>远逐层递减，且 inpainting 去除可见缺陷及跨缺陷类型迁移后增益仍存在，排除可见信号泄露和精确缺陷记忆化解释。

**BOUNDARYSUPPORT 核心设计**：
- 对干净图像 $x$ 应用过程干预 $g$（CutPaste-Scar、同类别 Poisson paste、同图局部形变+Poisson paste），生成合成视图 $\tilde{x}$ 和名义插入掩码 $A$。
- 像素级变化检测：$D(u) = \mathbf{1}\left[\frac{1}{3}\sum_c |\tilde{x}_c(u) - x_c(u)| > 1\right]$，将二值图 max-pool 到 token 网格得 $P(D)$。
- 排除集合 $C = P(A) \lor P(D)$，保留环 $R = \text{Dilate}(P(A), r=2) \setminus C$。膨胀施加于 $P(A)$ 而非 $C$，确保被 $P(D)$ 排除的 token 不扩张环边界。
- **记忆分支**：候选发现使用每层 $k{=}1$ 最近距离得分 $s_{\text{cand}}$，计算 $\Delta_p = s_{\text{cand}}(\tilde{x}, p) - s_{\text{cand}}(x, p)$；在 $p \in R$ 中筛选满足 $s_{\text{cand}}(x,p) \leq Q_{0.50}$、$\Delta_p \geq Q_{0.90}$、$\Delta_p > 0$ 的位置，将对应的 $F(\tilde{x})_p$ 与干净候选合并后以相同 $B$ 重新做 k-center 选择。
- **重建分支**（基于 Dinomaly 冻结编码器）：在原始硬 mining 损失 $\mathcal{L}_{\text{HM}}$ 基础上增加辅助损失 $\mathcal{L}_R = \frac{1}{2}\sum_{j=1}^2 \text{mean}_{p \in R}[1 - \cos(\text{sg}(E_j(\tilde{x})_p), G_j(\tilde{x})_p)]$，总损失 $\mathcal{L} = \mathcal{L}_{\text{HM}}(x) + 0.05\mathcal{L}_R$。合成核心 token 不参与损失但仍出现在输入中以提供上下文。

## 实验与结果
- **数据集**：MVTec AD（15 类）、VisA（12 类）、Real-IAD（30 类），均以正常训练集+标注测试集标准划分。
- **基线**：ProCon（记忆分支，DINOv2 ViT-B/14，5 个 bank）和 Dinomaly（重建分支，冻结 dino2reg vit base 14）。
- **主要结果（三 seed 均值±标准差）**：

| 分支 | 数据集 | Δ P-AP |
|---|---|---|
| Memory | MVTec | **+2.21 ± 0.04**（45/45 正） |
| Memory | VisA | **+1.82 ± 0.03**（36/36 正） |
| Memory | Real-IAD | **+1.76 ± 0.04**（90/90 正） |
| Recon. | MVTec | **+5.01 ± 0.07**（45/45 正） |
| Recon. | VisA | **+2.27 ± 0.38**（29/36 正） |
| Recon. | Real-IAD | **+4.20 ± 0.12**（84/90 正） |

- **诊断最强数字**：MVTec 固定预算 GT-正常 oracle 使 P-AP 从 73.34 升至 76.95；距缺陷 ≤2 格的近缺陷补丁恢复 94.70% 增益（76.76）。
- **匹配对照**：重建中用干净视图特征替代改变后上下文特征，MVTec P-AP 下降 7.13 点；记忆分支同等位置替换特征后 MVTec 下降 2.23 点（26/27 类下降）。
- **P-AP 为最佳主指标**：图像级 AUROC 基本持平或略降（如 Real-IAD 重建 ΔI-AUROC = −0.52），说明增益来自像素排序优化而非全局阈值漂移。

## 相关工作脉络
- **PatchCore / ProCon（记忆类）**：从干净训练补丁压缩 coreset；本文证明即使干净池本身也缺少缺陷邻域的有用正常特征，需在候选身份层面扩充而非仅改进搜索/打分。
- **Dinomaly / reverse distillation（重建类）**：学习干净特征重建目标；本文在同一重建框架上附加改变上下文后的邻域目标，且证明改变后上下文特征比干净特征更优。
- **SoftPatch / FUN-AD / InReaCh（污染数据学习）**：聚焦从被污染池中剔除不可靠补丁；本文关注干净池中本身缺失的有用特征，两者处理相反方向的失效模式。
- **CutPaste / NSA / DRAEM / GLASS（合成异常）**：将合成异常作为异常监督、定位信号或干净修复目标；本文以合成改变为手段改变上下文，但仅从像素保留的邻域特征中学习"正常"，合成核心本身不作为异常样本。
- **MuSc / INP-Former（缺陷图像内提取正常原型）**：从含缺陷测试图中挖掘正常证据；本文在训练阶段即通过上下文扰动暴露原本隐含的有用正常特征，且不依赖测试时标注。

## 局限性与未来方向
- **表征家族局限**：当前证据仅覆盖 DINOv2 ViT-B/14 的记忆与重建两个分支，其他编码器（如 ConvNeXt、Swin）的有效性待验证。
- **指标非单调改进**：P-AP 稳定提升但 I-AUROC 在部分 setting 下降（Real-IAD 重建 −0.52），说明定位增益与图像级分类之间存在 trade-off，论文未提供统一多目标的解决方案。
- **合成干预的通用性**：三种过程干预（CutPaste-Scar、Poisson paste、warp+paste）在开发集上均有效，但对特定工业场景（如高度结构化纹理）的最优干预类型尚未系统比较。
- **部署端真实缺失定位**：当前依赖合成上下文扰动来间接暴露缺失特征，如何直接在部署图像中识别并补全缺失的正常状态仍为开放问题。

## 研究启发与可借鉴点
1. **固定预算候选身份控制诊断法**：保持编码器、bank 大小、打分规则完全不变，仅替换候选来源，是量化"正常证据覆盖度"的干净实验设计，可迁移至其他自监督/半监督表示学习任务的覆盖度评估。
2. **改变上下文暴露隐式特征**：利用合成扰动使隐藏的正常特征进入可学习分布，而非直接增强数据或引入额外标注；该方法论可扩展至域适应、少样本学习和数据高效训练。
3. **像素保留环的严格排除机制**：同时使用名义插入掩码与实测 RGB 变化检测来确定排除集合，避免了单纯几何膨胀带来的假阳性保留，这一设计对任何"局部扰动+邻域学习"框架均有参考价值。
4. **跨范式对照验证有用特征来源**：在记忆和重建两个完全不同的计算范式下均做匹配控制，一致指向"改变后上下文特征更优"，增强了结论的可靠性，是模型机制分析的范例。

## 关键术语表
- **Fixed-budget diagnostic**：保持编码器、参考数量与打分规则完全不变，仅替换候选池组成，以隔离候选身份对性能的因果影响。
- **P-AP（Pixel Average Precision）**：将像素级异常分数排序后计算的平均精度，作为像素定位精度的主评估指标。
- **KCenter（近似 k-center）**：贪心选择 coreset 的算法，用于从候选特征子集中选取代表性子集作为 memory bank。
- **Altered-context feature**：同一空间位置在上下文被合成改变后由冻结编码器提取的特征，区别于原始干净视图的特征。
- **BoundarySupport ring（$R$）**：名义插入区域经膨胀后减去实际像素变化区域的 token 集合，即"像素保持不变但上下文已改变"的邻域 token 环。
- **GT-normal oracle**：使用真实缺陷图像中被掩码标注为正常的补丁作为额外候选的对照组，用于测量干净池的信息缺口。
- **ProCon**：Projection-Consistency memory，本文使用的记忆分支基线，基于冻结 DINOv2 特征与多 bank k-center coreset。
- **Dinomaly**：基于冻结 DINOv2 编码器的重建分支基线，通过瓶颈+解码器学习干净特征目标，残差作为异常证据。

## 可复现要素
- **数据集**：MVTec AD、VisA、Real-IAD，均为公开基准。
- **代码**：论文声明代码公开于 https://github.com/jw-chae/boundary_support。
- **权重**：使用预训练 DINOv2 ViT-B/14（冻结），无需额外训练编码器。
- **关键超参**：记忆 bank 比例 MVTec/VisA 为 5%，Real-IAD 为 1%；重建训练 5000 步，batch size=16，lr=$2\times10^{-3}$（cosine decay 至 $2\times10^{-4}$），辅助损失权重 0.05，环膨胀半径 $r=2$；候选筛选阈值 $Q_{0.50}$（clean view 得分）与 $Q_{0.90}$（$\Delta_p$）。
