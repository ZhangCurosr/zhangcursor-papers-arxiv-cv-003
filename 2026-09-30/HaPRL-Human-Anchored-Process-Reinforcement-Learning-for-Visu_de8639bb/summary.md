# 论文速读：HaPRL: Human-Anchored Process Reinforcement Learning for Visual Search Agent

## 一句话总结
本文提出了HaPRL，首个利用人类搜索行为作为锚点对多轮视觉搜索Agent的训练过程进行强化学习的框架。通过在冻结的判断器上引入任务自适应的加权过程评分机制，HaPRL不仅显著提升了准确率，更将搜索质量与正确轨迹对齐，在六个基准上全面超越基于结果的RL方法。

## 研究问题与动机
- **现有方法的根本缺陷**：主流视觉搜索Agent训练采用基于结果的RL（如GRPO），仅对最终答案进行二值奖励，导致"推理过程错误但答案碰巧正确"的假阳性轨迹获得全量奖励，优化沿错误路径扩展。
- **过程监督的迁移障碍**：数学推理中的过程监督依赖可独立判定的中间步骤，而视觉搜索中每次感知动作改变后续可用证据，轨迹整体才能评估质量，无法分解为离散步骤进行独立标注。
- **结果奖励的内在扭曲**：在VisualProbe Hard上，Outcome-RL使准确率提升28.6%，但正确答案的搜索质量反而下降8.4%，揭示了指标掩盖下的reward hacking现象。
- **人类信号的缺失**：人类在搜索过程中产生丰富的细粒度行为信号（鼠标轨迹、停留时长、缩放序列等），但这些信号在训练中被完全丢弃，本文首次将其作为实例级锚点引入RL。

## 核心贡献（创新点）
- **首个基于人类过程的视觉搜索RL框架**：首次将人类搜索轨迹作为奖励锚点而非策略示范，解决了过程监督在感知任务中难以离散化的核心难题。
- **任务自适应的五维过程评判器**：设计包含目标语义、证据获取、搜索进展、工具纪律、通信纪律五个维度的结构化评分框架，并根据任务类型（OCR/文本、计数/关系、属性、通用搜索）动态调整权重。
- **回答门控的奖励机制**：提出$r_{out} \times r_{proc}$的乘积奖励，将过程分数仅在答案正确时激活，既保留回答目标又实现正确轨迹间的梯度排序。
- **可缩放的流程标注范式**：证明仅需200条标注（占总数据18%）即可超越全量Outcome-RL，且400条流程监督初始化后接600条纯结果续训，可比全程结果训练多获得6.7×（6.13 vs. 0.91）的额外收益。

## 方法详解
**流程数据构建**：搭建浏览器标注平台，收集1,104条来自VisualProbe训练集的带行为日志数据。每个交互事件包含事件类型、时间戳、指针位置、速度/加速度、缩放框，经蒸馏压缩为按轮次记录的文本轨迹$H^*=(r_1^*,\ldots,r_L^*)$，保留扫描方向、停留、重定向和由粗到精的细化过程。

**人类锚定过程评判**：冻结的VLM评判器$J_\phi$接收$(I_0, q, \tau, H^*)$，输出五维得分向量$\mathbf{s}(\tau)\in[0,1]^5$。任务自适应权重$\mathbf{w}^{(p)}$根据问题类型分配，如OCR/text强调证据清晰度（$w_{Evd}=0.40$），count/relation强调空间覆盖（$w_{Tar}=0.20, w_{Evd}=0.35$）。过程分数为$r_{proc}(\tau)=\langle\mathbf{w}^{(p)},\mathbf{s}(\tau)\rangle$。

**回答门控的组相对优化**：答案评判器$J_{ans}$输出$r_{out}\in\{0,1\}$，训练奖励为$R_{HaPRL}(\tau)=r_{out}(\tau)r_{proc}(\tau)$。对每组G个轨迹进行组内标准化$A_i=\frac{R_i-\bar{R}}{\sqrt{G^{-1}\sum(R_j-\bar{R})^2+\epsilon}}$，使用clipped GRPO目标函数更新策略：$\mathcal{L}(\theta)=-\mathbb{E}[\min(\rho A,\text{clip}(\rho,1-\varepsilon,1+\varepsilon)A)]+\beta D_{KL}$。推理时不使用判断器和人类轨迹。

## 实验与结果是
**数据集与基准**：使用VisualProbe Easy/Medium/Hard、V*Bench QA、HR-Bench 4K/8K共六个基准，四个骨干网络（Qwen3-VL-4B/8B、LLaVA-OneVision-1.5-4B/8B），均经过Mini-o3轨迹冷启动。

**核心结果**：HaPRL在所有24个骨干-基准组合上超越Outcome-RL，平均提升幅度达+13.8%（Qwen3-VL-4B: 44.26 vs 33.98）。硬搜索子集VisualProbe Hard上，HaPRL相比Cold-Start提升+71.8%，峰值达+144.4%（Qwen3-VL-4B: 20.75 vs 8.49）。搜索质量方面，HaPRL在所有六个基准上正增长（平均+2.78），而Outcome-RL在VisualProbe Hard上反而下降-5.98点。

**可扩展性**：标注数据从200增至1,104条，准确率单调上升（36.62→44.26，+20.9%）。两阶段实验中，400条HaPRL初始化后接600条Outcome-RL续训，平均提升6.13分；同样续训量下，纯Outcome-RL仅提升0.91分，比例为6.7×。

**消融实验**：打乱配对导致性能暴跌至28.63（-15.63）；移除人类轨迹仅保留评判器降至36.41（-7.85，占全量增益76%）；10%事件噪声下仍保持41.74（-2.52）。替换方案对比：无参考33.98、纯工具奖励35.72、最终证据框38.61、教师生成路径39.85、人类轨迹44.26。

## 相关工作脉络
- **DeepEyes**（Zheng et al., 2025）：端到端RL训练主动感知，但仍依赖终端正确性；HaPRL通过人类轨迹提供实例级过程信号实现更细粒度控制。
- **Pixel Reasoner**（Wang et al., 2025a）：结合指令微调与好奇心驱动的RL；两者均利用辅助信号，但HaPRL使用跨实例的人类行为基准而非内部探索激励。
- **Chain-of-Focus**（Zhang et al., 2025）：SFT后接Outcome-RL；HaPRL在RL阶段引入过程维度，弥补了"正确答案由错误搜索获得"的漏洞。
- **PRM800K**（Lightman et al., 2024）：数学推理的步级过程监督；HaPRL解决的是无法分解为独立步骤的连续感知搜索问题。
- **Rubrics as Rewards**（Gunjal et al., 2025）：使用实例级rubric进行RL；HaPRL进一步引入跨实例的人类轨迹锚定，使rubric评估具备实例特定的参考基准。
- **URSA**（Luo et al., 2025）：将过程奖励纳入在线策略优化；但针对文本推理步骤，HaPRL将思路扩展到视觉搜索轨迹层面，处理感知动作改变证据可用性的独特挑战。

## 局限性与未来方向
- 当前仅在2D视觉搜索领域验证，需扩展到3D rigging、GUI Agent等人类行为信号丰富的交互场景。
- 人类标注成本较高（1,104条约27.6人时），虽然证明仅18%数据即可生效，但大规模应用的成本仍是瓶颈。
- 评估限于六个基准，未来需在更多视觉任务上验证流程对齐的通用性。
- 判断器依赖冻结大模型，推理阶段虽不使用，但训练成本较高；探索更轻量化的评判方案是潜在方向。
- 流程监督与冷启动效果的解耦分析表明两者可叠加，但最优的两阶段配比和调度策略尚待系统研究。

## 研究启发与可借鉴点
- **过程监督的可迁移范式**：从数学推理到视觉搜索，关键是将"可独立判定的步骤"扩展为"需整体评估的连续轨迹"，人类行为日志提供了实例特定的参考基准，这一思路可应用于其他需要过程对齐的agent训练（如代码生成、规划任务）。
- **任务自适应权重的设计模式**：根据任务类型动态调整多维权重（OCR强调清晰度、计数强调覆盖率），为多模态任务设计了灵活的评估框架，可推广到其他需要多维度判定的对齐任务。
- **回答门控的乘积奖励**：$r_{out}\times r_{proc}$机制在保证答案正确性的前提下引入过程排序，避免了纯过程监督可能导致的答非所问；这一设计可应用于任何既有明确答案又有过程质量的场景。
- **两阶段训练的缩放效应**：早期流程监督提供高质量初始化，后续结果扩展收益放大6.7×，提示训练schedule设计应优先考虑过程质量而非单纯增加结果数据量。
- **标注效率的帕累托改进**：18%标注数据超越全量无过程监督的结果，证明高质量人工信号的边际价值远高于廉价自动信号，值得在资源分配时优先投入。

## 关键术语表
**HaPRL**：Human-Anchored Process Reinforcement Learning，首个以人类搜索行为为锚点的视觉搜索Agent过程强化学习框架。
**VisualProbe**：多轮视觉搜索基准，按搜索难度分为Easy/Medium/Hard三个子集，关注目标大小与干扰密度。
**GRPO**：Group Relative Policy Optimization，Shao等人提出的组相对策略优化算法，本文作为训练基础框架。
**过程评判**：通过冻结VLM对rollout进行五维评分（目标语义、证据获取、搜索进展、工具纪律、通信纪律），衡量搜索质量而非仅看答案。
**回答门控**：仅当答案正确时激活过程分数（$R=r_{out}\times r_{proc}$），错误轨迹奖励为零，防止过程优化偏离答案目标。
**轨迹蒸馏**：将原始交互日志压缩为按轮次的文本轨迹，保留扫描方向、停留、重定向等信息，用于匹配模型rollout进行评分。
**任务自适应权重**：根据问题类型（OCR/text、count/relation、attribute、general search）分配五维评分的不同权重。
**Reward Hacking**：模型利用奖励函数的漏洞获得高奖励但不改善实际任务的行为；本文揭示Outcome-RL在准确率提升的同时搜索质量下降即为典型表现。

## 可复现要素
- **数据集**：VisualProbe训练集（公开），标注的1,104条人类轨迹及蒸馏后的$H^*$；附录C提及标注成本约27.6人时。
- **代码与权重**：已开源，github.com/zhangquanchen/HAPRL。
- **关键超参**：GRPO算法，每prompt 8个rollout，batch size 48，actor学习率$5\times10^{-7}$，KL系数$3\times10^{-3}$，max tool rounds 6，max images per context 6，图像像素范围$4\times10^4$至$10^6$。
- **Judge配置**：冻结Qwen3-VL-30B-A3B-Instruct，temperature 0，JSON输出；答案judge仅文本输入。
- **训练框架**：verl + vLLM rollout，硬件为8×H100或8×H20。
- **冷启动**：基于过滤后的Mini-o3轨迹（6,057条），LLaMA-Factory微调，lr $5\times10^{-6}$，5 epochs，ZeRO-3 offload。
