# 论文速读：Long-Time-No-See-Benchmarking-VLMs-for-Out-of-Sight-Spatiotemporal-Reasoning-in-Egocentric-Videos

## 一句话总结
本文提出了 **BEYOND3D**，首个针对第一人称视频中**视线外时空推理**（out-of-sight spatiotemporal reasoning）能力的VQA基准测试，要求模型追踪被操作并移出视野的物体，回答关于其最后可见时间、放置位置及3D空间关系的问题；当前最强VLM（Qwen-3.6-27B）仅达42.2%准确率，时间定位与空间状态维持仍是主要瓶颈。

## 研究问题与动机
1. **核心问题**：现实世界AI系统（如AR助手、家庭机器人）需要推理不在当前视野中的物体——不仅要回忆上次看到的位置，还要在物体被移动后更新其空间状态，并在其离开视野后保持该状态。
2. **第一人称视频的特殊挑战**：视角持续变化、物体被频繁操作和重新定位，使得"物体 permanence" 的推理远比静态场景复杂。
3. **现有基准的不足**：已有工作要么只测试静态3D场景（如VSI-Bench），要么虽涉及动态状态但未强制目标不可见（如HD-EPIC、EOC-Bench），无法直接评估模型在物体离开视野后保留**更新后空间状态**的能力。
4. **研究空白**：缺乏一个系统地、几何可验证地隔离"视线外时空推理"能力的评测基准。

## 核心贡献（创新点）
1. **新问题的形式化定义**：首次将"视线外时空推理"明确定义为追踪物体离开视野后的空间状态变化，为具身智能中的持久世界建模提供了新的评测维度。
2. **大规模几何感知基准BEYOND3D**：构建了9000个问题、8种诊断题型、覆盖135段第一人称视频的基准，通过结合3D物体位置、相机姿态和场景几何自动推断可见性轨迹，实现了无需人工标注的几何化可见性判定。
3. **四阶诊断性问答分解**：将推理链拆解为视觉定位→时间定位→场景定位→3D空间感知四个层次，使模型失败模式可归因。
4. **系统性VLM评测与失败模式分析**：评测9个通用与空间专用VLM，揭示时间证据检索是上游瓶颈、当前帧信息不足以支持视线外推理、空间预测存在严重先验偏差（集中于前方/近距离）。
5. **上游瓶颈验证消融**：通过预置"时间线索"（告知物体移动区间）和"可见性线索"（明确告知目标不可见）的干预实验，量化了各阶段的错误来源。

## 方法详解
**可见性轨迹构建（三阶段Pipeline）**：
- **Stage 1（视场投影）**：将物体9个支撑点（中心+四角+四边中点）从最近已知3D位置反投影至世界坐标，再用Project Aria的FISHEYE624鱼眼相机模型重投影到当前帧；超过50%点落在有效圆内则判为"in view"，否则为"out of view"。
- **Stage 2（几何遮挡检测）**：从相机中心向9个点发射射线，与厨房静态网格求交；若≥50%射线被阻挡（且首次交点比目标近δ=10cm），判为"occluded"；若遮挡主要来自可动部件（如柜门），标记为"fixture ambiguous"。
- **Stage 3（检测确认）**：用OWLv2开放词汇检测器对第一阶段通过且在view内的样本进行逐帧验证，若检测置信区间内至少50%帧成功匹配则判为"detected visible"，否则标记"visually unconfirmed"或"occluded"。

**查询锚点与问题生成**：
- 仅选取目标明确为"out of view"或"occluded"且处于静止状态的样本作为查询锚点$(o, T_q)$，排除瞬态动态遮挡造成的"visually unconfirmed"。
- 每个锚点生成8道多选题：视觉定位(1题)、时间定位(2题)、场景定位(1题)、3D空间感知(4题)，共8000道视线外问题+1000道可见控制组问题=9000题。
- 时间干扰项按±1-2s/±3-4s/±5-6s/±7-30s四个距离分箱采样，优先选择其他可见/移动事件的时间戳；空间答案类别均衡分布。

**3D空间答案推导**（公式）：
- 相机相对方向：$p_o^{\text{cam}} = R_q(\ell_o(T_q) - c_q)$，由旋转矩阵$R_q$和相机中心$c_q$将目标世界坐标转换到相机坐标系。
- 物体相对方向：$p_{o|r}^{\text{cam}} = R_q(\ell_o(T_q) - \ell_r(T_q))$，以可见参考物体$r$为原点、保持相机轴向。

## 实验与结果
**数据集**：基于HD-EPIC（第一人称厨房视频），135段视频、9位参与者、9个厨房、581个目标物体实例、561个参考物体实例；查询锚点按$T_q$（早/中/晚期）× 超出视野时长（短/中/长）三层分层采样。

**评测基线**：9个VLM（5个通用：Qwen-3.6-35B-A3B/27B、Qwen-3.5-9B、Qwen-3-VL-8B、InternVL-3.5-8B；4个空间专用：VLM-3R-7B、Spatial-MLLM-6B、Cambrian-P-7B、SenseNova-SI-8B），三种输入设置（Text Only、Last Frame Only + Text、Video + Text）。

**主要结果**：
- **最强模型**：Qwen-3.6-27B（Video + Text）宏观平均准确率**42.2%**，仅比随机猜测（29.7%）高12.5个百分点；文本-only基线平均31.9%。
- **各题型难度排序**（相对 chance）：Nearest Fixture最高（45.6% vs 22.7% chance），视觉定位次之（59.6% vs 50%），时间定位最低（+4.5%），3D空间感知最低（+3.6%）。
- **视频输入增益**：全局提升1.6-10.5%，其中Nearest Fixture提升最大（+14.4%），时间定位提升有限。
- **通用 vs 空间专用**：通用模型全面领先；最大模型Qwen-3.5-9B（38.6%）已超越所有同等规模的空间专用模型（31.6-37.2%），说明空间特化训练与本文任务的时序-状态维持需求存在错位。
- **当前帧 vs 全视频**：Last Frame Only使Visibility Check提升至70%，但时间/场景/3D任务仍接近随机；全视频输入对Last Placement Time（19.0%→25.4%）、Nearest Fixture（25.5%→45.6%）有显著增益。
- **Horizon效应**：短/中/长时间跨度宏平均分别为40.4%/34.8%/31.9%，证明超出视野时长是主要难度驱动因素。
- **消融**：预置时间线索（告知所有移动区间）后所有下游题型均提升；额外加入可见性提示后Nearest Fixture再+8%，但3D任务仅+0-2.4%。

## 相关工作脉络
1. **EgoTempo [27] / EgoMemReason [36]**：评测VLM的时间理解和记忆能力，但未要求目标物体在查询时不可见，也未强制3D空间状态的更新与保持。
2. **VSI-Bench [39] / EOC-Bench [43]**：侧重静态或准静态3D场景理解，未涉及第一人称视角下物体被主动操作后移出视野的动态推理。
3. **HD-EPIC [25] / EgoDynamic4D [18]**：提供丰富的第一人称物体移动标注，但评测不强制目标不可见，允许模型利用当前帧捷径作答。
4. **Ego4D-VQ3D [15]**：检索先前观察到的静态物体位置，但不追踪物体被移动后的状态更新。
5. **SpaMEM [22]**：在合成环境中评估空间状态修订，但非真实第一人称视频，且不含视线外条件。
6. **AMEGO [14] / OSNOM [26] / Whareformer [6]**：具身系统中的持久世界状态表征方法，属于模型架构方向而非基准评测，与本文形成互补。
7. **本文定位**：首次在真实第一人称视频中，通过几何可验证的可见性判定，系统性隔离并评估模型对"被移动后移出视野的物体"的时空推理能力。

## 局限性与未来方向
1. **场景单一**：数据来源于厨房环境（HD-EPIC），泛化到家居、户外等其他动态场景有待验证。
2. **可见性轨迹推断误差**：人类审计准确率达83.5%，但主要错误集中在"visually unconfirmed"状态（OWLv2漏检），部分锚点可能因检测失败被错误排除。
3. **1fps时间分辨率**：对于秒级精度的时间定位问题，帧率可能不够；干扰项设计依赖事件边界，密集交互场景下可能区分度不足。
4. **离散分类答案**：3D空间问题使用离散方向/距离分箱，无法反映模型的连续空间感知能力。
5. **未来方向**：扩展至更多场景和物体类型；引入连续3D坐标预测；结合显式3D重建/占据网络构建持久潜在表示；探索长上下文与显式记忆的联合建模。

## 研究启发与可借鉴点
1. **诊断性任务分解**：将复杂推理拆解为视觉定位→时间定位→场景定位→3D空间感知四层递进问题，使失败归因清晰，值得借鉴到多阶段推理基准的设计中。
2. **几何感知的可见性推断Pipeline**：三步法（视场投影→几何遮挡→开放词汇检测）可迁移到其他需要自动判定物体可见性的场景，减少对人工标注的依赖。
3. **分层时间 stratification**：按查询时间和超出视野时长双重分层采样，有效控制了时间维度的混淆变量，是视频理解基准设计的优秀范例。
4. **上游瓶颈干预消融**：通过预置时间线索和可见性线索的半 oracle 实验，精准定位了错误来源（时间检索 vs 空间状态维持 vs 可见性判断），为模型改进指明了方向。
5. **与团队方向的结合机会**：可将"持久潜在状态表示"（如persistent world model、object permanence embedding）与VLM结合，专门针对视线外推理进行微调；也可将几何可见性推断模块作为预过滤层集成到长视频理解Pipeline中。

## 关键术语表
**Out-of-sight Spatiotemporal Reasoning**：追踪物体离开视野后的空间状态变化，并在其不可见时仍能推理其位置和空间关系的能力。
**BEYOND3D**：本文提出的首个专门评测视线外时空推理能力的VQA基准，包含9000题、8种题型、135段第一人称视频。
**Visibility Track**：按1fps粒度记录的物体可见状态序列（可见/视野外/遮挡/视觉未确认/运动中），由三阶段几何+检测Pipeline自动推断。
**Query Anchor $(o, T_q)$**：查询锚点，由目标物体$o$和查询时刻$T_q$组成，要求$o$在$T_q$前已被移动且在$T_q$时静止但不可见。
**Out-of-sight Horizon $h(o, T_q)$**：超出视野时长，即$T_q$减去$o$最后一次可见的时间，衡量记忆保持的时间跨度。
**Fixture**：支撑或容纳物体的场景固定装置（如counter、drawer、fridge），用于场景定位问题。
**Geo-Vis（Geometry-aware Visibility）**：利用3D场景几何（相机姿态、物体位置、静态网格）推断可见性的方法，区别于纯视觉检测。
**Diagnostic Decomposition**：将复杂推理任务分解为多个独立可评估的子问题，用于精确定位模型失败模式。

## 可复现要素
- **数据集**：BEYOND3D基于HD-EPIC构建；HD-EPIC需申请访问权限（https://hd-epic.github.io/）；BEYOND3D标注数据随论文开源（参见项目页面）。
- **代码**：论文提供项目页面和项目代码链接（$\S$ Code），评估脚本和预处理Pipeline已开源。
- **模型**：使用各模型官方checkpoint，无任务特定微调；所有推理在单卡A100/RTX PRO 6000上进行。
- **关键超参**：可见性推断阈值δ=10cm；鱼眼有效区域判据为50%投影点；检测匹配框扩张20像素；OWLv2检测阈值50%帧；FPS=1；视频预处理分辨率448×448。
- **输入格式**：1fps视频前缀（至$T_q$），查询帧保留，鱼眼外部区域黑 Mask，时间戳token叠加于右下角，参考物体叠加8×8红色标记。
