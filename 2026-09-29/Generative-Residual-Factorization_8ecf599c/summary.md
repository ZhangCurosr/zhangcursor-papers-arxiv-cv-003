# 论文速读：Generative Residual Factorization

## 一句话总结
本文在共享场景因子假设下严格证明：下一图像 patch 的条件分布可因子化为“场景因子后验”与“残差核”的混合，条件熵随之精确分裂为不可消除的残差熵与可压缩的后验项。研究进一步揭示方向性 embedding 预测（如 NEPA）对投影纤维不可识别且可能被常数嵌入最小化，而在 Gaussian 与有限字母模型中给出闭式解，并在 MNIST/CIFAR-10 上通过双探针实验验证理论分裂。

## 研究问题与动机
- **生成器与表征的本质混淆**：生成器是条件采样律，表征是过去的充分统计量，两者在数学上是不同对象，但现有工作常将优化后验信息的目标等同于建模生成核。
- **条件熵的构成机制不清**：预测不确定性中，哪些部分可通过改进历史表征消除，哪些是任何观测都无法消除的固有残差，缺乏统一的信息论刻画。
- **方向性损失的理论盲区**：自监督中广泛使用的 next-embedding prediction 仅通过浅层映射观察目标，其损失函数的识别边界、是否存在平凡解（如常数嵌入）尚未被严格分析。
- **理解与生成脱节的理论根源**：为何强编码器/高语义奖励能提升判别性能却未必改善生成质量？本文指出奖励或分类信号只能修正后验，无法指定残差核，从理论上解释了这一 gap。

## 核心贡献（创新点）
1. **生成残差因子化定理**：严格证明 $p(x_{t+1}|x_{\leq t}) = \int p(x_{t+1}|s)p(s|x_{\leq t})ds$，将条件律分解为后验混合与残差核，区别于仅依赖经验损失或 ELBO 近似的经验性工作。
2. **条件熵的精确分裂**：导出 $H(x_{t+1}|x_{\leq t}) = \mathbb{E}[H(x_{t+1}|s)] + I(x_{t+1};s|x_{\leq t})$，首次将预测不确定性定量拆分为不可约残差熵与可压缩后验项，为表征容量与生成能力的解耦提供理论基准。
3. **方向性损失的纤维不可识别性**：证明任何仅通过可测映射 $g(x)$ 观察目标的损失对纤维内样本无区分力，且当假设类包含非零常数嵌入时余弦损失可达全局下界 $-1$，揭示 NEPA 类目标的内在识别瓶颈。
4. **KL 散度在双因子上的独立上界**：证明后验误差与残差核误差对生成 KL 的贡献相互独立（Prop 5），纠正“优化单一目标即可兼顾两者”的常见误区。
5. **可计算的理论-实验诊断框架**：在 Gaussian/二元信道给出闭式表达式，并在 MNIST/CIFAR-10 上同步报告 probe 准确率与 residual MSE，实验排序与理论预测一致。

## 方法详解
- **共享因子模型设定**：$s \sim p(s)$，给定 $s$ 时 $x_t \perp x_{\leq t} | s$，$x_t|s \sim p(x_t|s)$。$p(x|s)$ 为残差核，$s$ 为跨 patch 共享的场景因子，私有噪声仅影响单个 patch。
- **后验因子化（Prop 1）**：$p(x_{t+1}|x_{\leq t}) = \int p(x_{t+1}|s)p(s|x_{\leq t})ds$。若 $r=r(x_{\leq t})$ 是充分统计量（$s \perp x_{\leq t}|r$），则后验可替换为 $p(s|r)$，但残差核 $p(x|s)$ 保持不变。
- **熵分裂（Prop 2 / Cor 1）**：$H(x_{t+1}|x_{\leq t}) = \mathbb{E}[H(x_{t+1}|s)] + I(x_{t+1};s|x_{\leq t})$。残差熵 $\mathbb{E}[H(x|s)]$ 与历史信息量无关；仅后验项 $I(\cdot)$ 随表征增强而下降，下界当且仅当 $I=0$（即过去已完全确定 $s$）时达到。
- **KL 分裂（Prop 5）**：生成器 $q(x|r)=\int p(x|s)q(s|r)ds$ 与真实条件 $p(x|r)$ 的 KL 满足：后验错误时 $\mathrm{KL} \leq \mathrm{KL}(p(s|r)\|q(s|r))$；残差核错误时 $\mathrm{KL} \leq \mathbb{E}[\mathrm{KL}(p(x|s)\|q(x|s))]$。两类误差可独立存在且互不补偿。
