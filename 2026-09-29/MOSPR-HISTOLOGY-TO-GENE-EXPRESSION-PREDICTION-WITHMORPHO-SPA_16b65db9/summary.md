# 论文速读：MOSPR: HISTOLOGY-TO-GENE EXPRESSION PREDICTION WITH MORPHO-SPATIAL MACROSTATES AND LOW-RANK MOLECULAR PROGRAMS

## 一句话总结
论文提出 MoSPR（形态-空间程序回归），一种线性框架，通过队列级形态学宏观状态表示与低秩基因表达基底的联合建模，实现从 H&E 全切片图像到批量 RNA 测序的高精度基因表达预测，并在 TCGA 三个癌症队列上取得最优性能。

## 研究问题与动机
- **核心问题**：从组织病理学图像推断分子特征（基因表达）是一个重要的临床与科研需求，因为分子检测成本远高于 H&E 染色。
- **现有方法的不足**：
  1. 全局池化与标准多示例学习（MIL）无法显式编码形态状态的**空间邻接关系**。
  2. Transformer 与图方法依赖患者级别的 patch 集合或图，难以捕捉队列级别的重复空间组织结构。
  3. 直接预测数千个基因的表达存在维度灾难，且未利用基因表达间的强相关性结构。
- **本文动机**：构建一个紧凑的、基于队列级别的形态-空间表示，耦合低秩分子回归，以低成本实现高精度、可解释的基因表达预测。

## 核心贡献（创新点）
1. **队列级形态词典学习**：通过冻结 patch 嵌入的 k-means 聚类 + 邻接矩阵聚合 + 谱嵌入，从无空间转录组监督的情况下学习共享的宏观状态（macrostates），每个 slide 表示为全局形态向量与宏观状态偏差的拼接。
2. **线性低秩分子回归框架**：将高维基因表达目标通过 PCA 压缩为 q 维低秩基底，再拟合 ridge 回归将形态表示映射到分子系数，实现 $\hat{Y} = X W_q U_q$ 的精确分解。
3. **可解释的宏观状态-分子贡献解耦**：线性结构允许将每个预测的表达谱精确分解为全局形态贡献与各宏观状态贡献之和，无需后验归因方法。
4. **系统性三队列评估**：在 TCGA-BRCA/KIRC/LUAD 上，MoSPR 在基因级 PCC/SCC 与 Hallmark/GO-BP/KEGG 通路级 SCC 上均取得最优，且仅需 0.96M 参数与 2.02 GFLOPs。
5. **数据效率优势**：在 BRCA 队列上，使用约 44% 训练数据即可达到最强基线（ABMIL）的全数据基因预测性能，显示形态-空间表示对有限标注的强鲁棒性。

## 方法详解
### 3.1 Patch 特征提取
- 使用冻结的病理编码器 $f_{enc}$（CONCH，$D_0 = 512$）将每个 patch $x_i^{(n)}$ 映射为嵌入 $z_i^{(n)} \in \mathbb{R}^{D_0}$。

### 3.2 微观状态 → 宏观状态构建
1. **微观状态分配**：对训练集 patch 嵌入做 k-means（$J=200$ 簇），每个簇中心 $\mu_j$ 为一个微观状态。
2. **邻接矩阵构造**：对每个患者，统计 8-邻域 patch 对的微观状态转移频率，得到对称矩阵 $C^{(n)} \in \mathbb{R}^{J \times J}$。
3. **队列级聚合**：对每个患者的 $C^{(n)}$ 按总质量归一化后取平均，得到全局邻接矩阵 $C_{global}$。
4. **谱嵌入与宏观状态发现**：对 $C_{global}$ 行归一化得转移矩阵 $P$，计算其特征分解，保留前 $L=20$ 个非平凡特征向量，加权嵌入后再次 k-means（$K=8$ 簇）得到宏观状态 $\rho: \{1,...,J\} \rightarrow \{1,...,K\}$。

### 3.3 形态-空间低秩回归
1. **结构化表示**：
   - 全局形态向量：$M_n = \frac{1}{N_n} \sum_i z_i^{(n)}$
   - 宏观状态偏差：$s_{nk} = p_{nk}(h_{nk} - M_n)$，其中 $h_{nk}$ 为属于宏观状态 $k$ 的 patch 均值
   - 最终表示：$X_n = [M_n \mid S_n] \in \mathbb{R}^{(K+1)D_0}$
2. **低秩分子基底**：对标准化基因表达矩阵 $Y_z$ 做 PCA，取前 $q$ 个主成分得 $U_q \in \mathbb{R}^{q \times G}$，系数矩阵 $A_q = Y_z U_q^\top$。
3. **回归与重构**：拟合 ridge 回归 $W_q^* = \arg\min_{W_q} \|A_q - XW_q\|_F^2 + \lambda_{ridge}\|W_q\|_F^2$，预测为 $\hat{Y}_z = X W_q^* U_q$。

### 3.4 宏观状态级分子解释
- 将 $W_q^*$ 按块分解为全局权重 $W_{q,global}^*$ 与各宏观状态权重 $W_{q,k}^*$。
- 预测谱可精确分解：$\hat{Y}_{z,n} = \Gamma_{n,global} + \sum_k \Gamma_{nk}$，其中 $\Gamma_{nk} = s_{nk} W_{q,k}^* U_q$。

## 实验与结果
### 数据集与协议
- TCGA-BRCA（1,037 患者，14,042 基因）、TCGA-KIRC（342 患者，14,295 基因）、TCGA-LUAD（482 患者，14,514 基因）。
- 患者级别 4-fold 交叉验证，内层选择超参数。

### 评估指标
- **基因级**：基因-wise PCC 与 SCC 的平均值。
- **通路级**：从预测/真实表达计算通路得分（成员基因的 z-score 均值），报告各通路集合（Hallmark、GO-BP、KEGG）的 median SCC。

### 主要结果
| 队列 | 方法 | PCC | SCC | 通路 median SCC（Hallmark）|
|------|------|-----|-----|---------------------------|
| BRCA | MoSPR | **0.413** | **0.411** | **0.551** |
| BRCA | 最强基线（MambaMIL） | 0.363 | 0.356 | 0.479 |
| KIRC | MoSPR | **0.334** | **0.348** | **0.402** |
| KIRC | 最强基线（MambaMIL） | 0.290 | 0.290 | 0.308 |
| LUAD | MoSPR | **0.358** | **0.376** | **0.528** |
| LUAD | 最强基线（MambaMIL） | 0.319 | 0.335 | 0.529 |

- **提升幅度**：BRCA PCC/SCC +0.043/+0.048，KIRC +0.022/+0.029，LUAD +0.039/+0.040。
- **通路级**：在 9 个比较（3 队列 × 3 通路集合）中占优 8 个，最高提升达 +0.051。
- **模型效率**：仅 0.96M 参数、2.02 GFLOPs，远低于多数深度基线。

### 消融分析（BRCA）
| 变体 | 输入 | 输出 | 基因 SCC | Hallmark SCC |
|------|------|------|----------|--------------|
| Global Direct | M | 直接 | 0.348 | 0.458 |
| Global Low-Rank | M | $U_q$ | 0.380 | 0.481 |
| Spatial Direct | [M S] | 直接 | 0.395 | 0.552 |
| Spatial Low-Rank (MoSPR) | [M S] | $U_q$ | **0.411** | **0.551** |
| Shuffled-State Low-Rank | 乱序宏观状态 | $U_q$ | 0.379 | 0.499 |

- 宏观状态表示与低秩回归具有互补增益。
- 乱序宏观状态性能下降，验证邻接驱动的宏观状态组织的必要性。
- 宏观状态划分在 300 次 bootstrap 下稳定（BRCA ARI=0.769，KIRC=0.653，LUAD=0.786）。

### 数据效率
- MoSPR 使用 ~44% 训练数据即可匹配 ABMIL 的全数据基因预测性能。
- ~48% 训练数据即可匹配 ABMIL 的全数据 Hallmark 通路重建性能。

## 相关工作脉络
1. **HE2RNA (Schmauch et al., 2020)**：首个 H&E→RNA 深度学习模型，采用 patch 级深度网络直接预测基因表达；MoSPR 与其本质区别在于引入队列级形态词典与线性回归，避免患者级深度特征的学习。
2. **AbReg (Graziani et al., 2022)**：注意力机制回归基因表达；MoSPR 不使用注意力，而是通过谱嵌入的宏观状态捕获空间组织。
3. **tRNAformer (Alsaafin et al., 2023)**：Transformer 架构预测 RNA；MoSPR 以线性框架替代，参数量更低且具解析可解释性。
4. **MOSBY (Şenbabaoğlu et al., 2024)**：多组学推理与空间生物标志物发现；MoSPR 仅用批量 RNA 监督，不依赖空间转录组。
5. **TransMIL (Shao et al., 2021) / Patch-GCN (Chen et al., 2021)**：患者级 patch 图/序列建模；MoSPR 的邻接结构是队列共享的，不依赖患者特定图。
6. **CPNN (Nishimura et al., 2026)**：单细胞原型融入分子结构；MoSPR 无此设计，但通过宏观状态偏差间接捕获形态异质性。

## 局限性与未来方向
- **宏观状态的二维局限**：当前宏观状态基于局部 8-邻域邻接，未建模完整二维组织几何结构。
- **批量 RNA 的验证限制**：无法直接验证宏观状态关联的分子程序是否真正空间局域化，生物学表征仍为定性。
- **外部泛化未验证**：仅在 TCGA 内部评估，跨机构、跨扫描仪、跨人种的泛化能力未知。
- **未来方向**：结合空间转录组数据进行验证；探索更高维度的空间邻接建模；扩展到独立外部队列与真实临床部署场景。

## 研究启发与可借鉴点
1. **队列级谱嵌入词典**：将 patch 聚类 + 邻接矩阵聚合 + 谱嵌入的组合可迁移至其他 WSIs 的共享形态字典学习任务。
2. **低秩输出压缩**：对高维回归目标做 PCA 降维再线性回归，是一种轻量且有效的多维输出预测范式，适用于蛋白质组、甲基化等其他组学预测。
3. **线性分解的可解释性**：将预测输出精确分解为全局与组件贡献，无需后验归因，这种代数可分解性值得在其他可解释 AI 场景中借鉴。
4. **数据效率优势**：形态-空间表示对标注数据的低依赖性提示，在有限配对 H&E-RNA 数据场景下，此类方法比深度端到端模型更具实用价值。
5. **宏观状态与通路富集的关联**：论文展示了宏观状态可与氧化磷酸化、EMT、干扰素响应等通路过表达关联，为"形态-分子"桥梁提供了生物学可解释路径。

## 关键术语表
- **MoSPR (Morpho-Spatial Program Regression)**：形态-空间程序回归，本文提出的线性预测框架。
- **Microstate (微观状态)**：冻结 patch 嵌入经 k-means 聚类得到的 200 个形态原语。
- **Macrostate (宏观状态)**：由微观状态的谱嵌入再聚类得到的 8 个共享形态-空间集群。
- **Global morphology vector (M)**：slide 所有 patch 嵌入的均值，捕获全局形态统计。
- **Macrostate deviation vector (S)**：各宏观状态内的 patch 均值相对于全局均值的丰度加权偏差。
- **Low-rank expression basis (U_q)**：基因表达矩阵的 PCA 前 q 个主成分，将 G 维目标压缩为 q 维。
- **Adjusted Rand Index (ARI)**：衡量宏观状态划分的稳定性，值越接近 1 表示划分越一致。
- **Pathway score**：通路内基因 z-score 的均值，用于评估预测谱的功能一致性。

## 可复现要素
- **数据集**：TCGA-BRCA/KIRC/LUAD 的 H&E WSIs 与批量 RNA-seq，公开可用（TCGA 数据仓库）。
- **代码**：已开源，见 https://github.com/Radisen-Panthera/MoSPR。
- **预训练编码器**：CONCH（Lu et al., 2024），$D_0=512$，冻结使用。
- **关键超参数**：$J=200$（微观状态数）、$K=8$（宏观状态数）、$L=20$（谱分量数）、$q \in \{4,8,16,32,48,64,96,128\}$（分子秩）、$\lambda_{ridge} \in \{1,10,10^2,10^3,10^4,10^5\}$。
- **交叉验证**：患者级别 4-fold，内层验证集选择 $(q, \lambda_{ridge})$。
- **基因预处理**：log1p(TPM per $10^4$) 后按基因标准化（仅用训练 fold 统计）。
