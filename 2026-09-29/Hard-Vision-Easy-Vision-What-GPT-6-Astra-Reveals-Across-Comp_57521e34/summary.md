# 论文速读：Hard-Vision-Easy-Vision-What-GPT-6-Astra-Reveals-Across-Comp

## 一句话总结
本文系统评估以 GPT-6 Astra 为代表的前沿通用 AI 系统在计算机视觉各领域的能力边界，揭示出语义理解、结构预测类"易视觉"任务已可到达或超越专用模型水平，而度量几何精度、忠实重建、时序一致预测、专业细粒度视觉知识等"硬视觉"任务仍存在显著差距。

## 研究问题与动机
- 前沿通用系统正快速扩展视觉能力，但现有基准分散于不同任务、领域和模型比较，缺乏 Landscape-level 的系统性分析，难以回答"通用接口能覆盖多少计算机视觉"这一核心问题。
- 单一模型在某个基准领先，未必能迁移到相关任务；其性能与专用模型、人类水平的相对位置尚不明确，需要统一坐标系进行跨任务对照。
- 增加推理努力（reasoning effort）与显式工具调用是否能有效填补这些差距，以及相应推理/工具成本如何，目前缺乏定量证据。
- 计算机视觉传统分工（识别、检测、分割、几何、视频、生成、专家域）正在被通用系统重塑，需要重新划定通用与专用的能力边界以指导后续研究与应用。

## 核心贡献（创新点）
1. **首次在9大CV领域、34项能力、55个基准上统一评估6个前沿通用系统并与专用模型和人类参照对比**：与已有分散评测不同，本文提供跨任务、跨领域的标准化能力成熟度地图。
2. **提出"易视觉 vs 硬视觉"的能力分层范式**：通用系统擅长语义解释与对象-centric 预测，而在度量几何、忠实重建、时序一致预测、细粒度专业判别上仍面临实质性差距。
3. **定量刻画推理努力与工具调用的增益与代价**：不同能力对更强推理的响应差异显著，部分任务可接近专家水平，但推理成本最高可达基线的 13.22 倍。
4. **提出通用-专用分工的可操作框架**：建议语义理解/推理/规划内化于通用模型，而度量几何、高保真重建、密集对应、罕见专家域细粒度判别更适合作为工具调用。

## 方法详解
- **评测架构**：统一指令、视觉输入与评分协议，对6个前沿通用系统（GPT-6 Astra、Fable 5、Kimi K3、Gemini 3.1 Pro、Qwen 3.8-Max、Muse Spark 1.3）在55个基准上平行评测。
- **参照系**：对每个能力选取最强专用模型或先前行通用SOTA作为 Reference Model，并在可用时引入人类基准；以 Best model vs ref. 衡量距专家/人类的剩余空间，以 Best vs 2nd best 刻画系统间优势幅度。
- **能力成熟度四分档**：exceeds reference level（>110%）、at reference level（100–110%）、approaching（85–100%）、substantial gap（<85%），用于跨任务汇总。
- **任务覆盖**：识别与视觉阅读、视觉/空间推理、2D/3D定位与分割、深度与3D重建、视频理解与分割、图像生成/编辑/修复/质量评估、机器人（驾驶场景、具身理解、导航）、专家域（医学、遥感、显微病理）。
- **输出后处理**：分割多边形栅格化为像素掩码；深度预测渲染为稠密深度图或与相机参数结合生成点云；3D检测/定位转换至边界框或角点；病理实例/类别图转换为细胞核多边形与组织掩码，分别用于检测与分割评分。
- **生成/编辑配对**：GPT-6 Astra 配 GPT Image 2.5 Sunburst、Qwen 3.8-Max 配 Qwen Image 3 Pro、Muse Spark 1.3 配 Muse Image、Gemini 3.1 Pro 配 Gemini 3.1 Flash Image；推理模型负责指令格式化，图像模型负责生成/编辑。
- **推理配置**：支持 high/xhigh/max 等多档推理努力；工具调用实验包括计数时先定位再计数、使用深度/分割模型辅助推理等。
- **成本度量**：以推理成本比率（相对低努力基线）与得分比率双维度呈现，强调增益-代价权衡。

## 实验与结果
- **数据与基线**：55个基准（含 MMStar、MathVista、RefCOCO、DAVIS、MS-CXR、LOL-v1、GenEval2 等），各任务对应最强专用参考（如 Rex-Omni 检测、SAM 3 Agent 分割、DA3 深度、WildDet3D 3D检测、BEE 视频分割、MIRAGE 修复等）。
- **视觉识别/阅读**：OCR 最高 98.1，接近人类 98.0；文档/图表理解所有模型均超越人类（最高 +3.5）。
- **视觉与空间推理**：数学推理全部达到或超越人类（78.8–92.5 vs 78.7）；2D 空间推理 GPT-6 Astra 达人类水平（96.0 vs 95.8）；3D/多视角推理仍有差距（89.6 vs 94.1）。
- **2D 定位**：GPT-6 Astra 在目标检测（89.1 vs 参考 78.4，+10.7）与分割（81.3 vs 77.0，+4.3）均超过专用模型；视觉定位 93.1，接近人类 96.2。
- **3D 感知**：3D 视觉定位 GPT-6 Astra 达 73.8，远超其他系统（+10.7 over 2nd best）；3D 检测 17.3 与参考 16.8 接近；深度估计 AbsRel 0.63 仍劣于 DA3 的 0.44；多视图重建误差约为专家 2.3 倍。
- **视频**：理解 74.3 vs 参考 71.5，接近专家；视频分割 84.5 vs 91.0（BEE），最佳 vs 次佳优势 +26.6。
- **生成/编辑/质量评估**：GPT-6 Astra 在三项均超过参考（+3.6 / +0.16 / +1.3）。
- **图像修复**：GPT-6 Astra 17.7 dB vs MIRAGE 30.7 dB，差距达 -13.0 dB；视觉 plausible 但存在幻觉（如图7所示），忠实度不足。
- **机器人**：驾驶场景 80.8 vs 参考 73.1（+7.7）；具身理解 82.3 vs 78.5（+3.8）；导航成功率 78%。
- **专家域**：医学理解 86.0 vs 81.5（+4.5）；3D 医学定位 73.9；但2D医学定位仅 61.5 vs 81.8（-20.3）；显微病理 Macro-F1 最高 23.8，远低于专家 57.1 与人类 82.0。
- **结论**：最强结果集中在 GPT-6 Astra 的视频分割（84.5）、2D 检测/分割超过专家、3D 视觉定位优势显著；最大剩余差距在图像修复（-13.0 dB）、显微病理（-33.3 / -58.2）、深度估计与多视图重建。

## 相关工作脉络
- 与 BLINK 等指出 MLLM "能看到但无法感知" 的工作对话：本文进一步按能力分层，明确哪些子能力真正感知到位、哪些仍停留在语义层面。
- 对比 V*、PerceptionBench 等细粒度感知评测：本文范围更广（9域34能力55基准），并以参考模型/人类为锚点给出成熟度分层。
- 与 SAM/Depth Anything 等专用视觉 foundation 比较：证明通用接口在目标检测、分割、3D 定位等结构预测上可达到或超越专用模型。
- 与专用视频分割（BEE）、深度（DA3）、重建（VGGT-1B）、修复（MIRAGE）对照：显示时序稠密预测与高保真重建仍是硬骨头。
- 与专家域 VLM（RadVLM、M3D、HoVer-NeXt 等）对照：揭示"能定位但不擅长细粒度判别"的专家域鸿沟。
- 相对 Reasoning Segmentation/LISA 等工作：通用系统通过指令+推理可直接完成结构预测，减少对专用管线依赖；但在需要 metric 精度和忠实度的子任务仍需工具或专用模型。

## 局限性与未来方向
- 评测依赖各基准的人类/专家参照，部分任务（如 3D 医学定位）缺少强参考，成熟度评估存在天花板效应。
- 推理努力的提升带来显著成本增长（最高 13.22×），在实际部署中的性价比尚未充分讨论。
- 工具调用与专家模型集成的策略（何时调用、调用哪类工具、如何验证输出）仍待系统化研究。
- 未来方向包括：内化哪些视觉能力、保留哪些作为工具；设计高效的多模态 agent 架构以在准确率/延迟/成本间取得平衡；针对"硬视觉"任务发展高保真、度量一致的生成与预测能力。

## 研究启发与可借鉴点
- **分层能力评估思路可直接迁移**：用"成熟度四分档 + 双维度差距（vs ref / vs 2nd best）"刻画任意新模型在多任务谱系中的定位。
- **推理-成本帕累托曲线具有复用价值**：以 score ratio 与 cost ratio 双轴分析不同 effort 档位，可指导团队在资源受限场景下选择最优点。
- **专家-as-tool 混合架构值得采用**：通用大模型负责语义理解/规划，深度/分割/修复等专用模型负责高保真输出，本文明确了该分工的适用边界。
- **幻觉与忠实度的区分评测**：图像修复等任务中"视觉合理"不等于"像素忠实"，可在下游工作中引入 fidelity-sensitive 子集（医学、遥感、科学图像）作差异化评测。
- **34 能力 × 9 域的评测模板可复用到新系统**：后续引入新通用模型时，可直接沿用该 benchmark 集合与后处理流程进行横向对比。

## 关键术语表
- **Hard Vision / Easy Vision**：Hard Vision 指需要度量几何精度、忠实重建、时序一致或专业细粒度知识的能力；Easy Vision 指可通过语义解释与对象中心推理近似专家水平的能力。
- **Reference Model**：各任务选取的最强专用模型或先前行通用SOTA，作为能力成熟度的对标基线。
- **Maturity Tier**：将能力划分为超过/达到/逼近/显著落后参考水平四个成熟度档位。
- **Reasoning Effort**：模型推理过程的投入档位（high/xhigh/max），以得分比与成本比量化增益与代价。
- **Specialist-as-Tool**：将深度/分割/修复等专用模型作为通用系统的工具调用，弥补通用接口在精确输出上的不足。
- **gIoU / OKS AP / J&F**：通用语义交并比、基于关键点匹配的平均精度、视频分割的联合精度与召回率，分别为分割、姿态、视频分割的核心指标。
- **AbsRel**：平均绝对相对深度误差，越小越好；本文用于量化深度估计的度量精度。
- **Structured Prediction**：输出为边界框、掩码、深度图、3D 体素或时序掩码序列等非标量结构化结果的预测任务。
