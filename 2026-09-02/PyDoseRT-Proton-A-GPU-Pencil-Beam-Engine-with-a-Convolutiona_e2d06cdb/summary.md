# 论文速读：PyDoseRT-Proton：基于卷积残差修正网络的 GPU 铅笔束质子剂量计算引擎

## 一句话总结
本文提出了 PyDoseRT Proton，一种面向 DoseRAD2026 挑战的混合方法：将可微分的 GPU 加速解析铅笔束（PB）剂量引擎与一个轻量级 3D 卷积残差 U-Net（RepVGG–U-Net，约 887K 参数）相结合，以蒙特卡洛（MC）精度实现快速质子剂量计算。物理引擎提供稳定的解析基线，残差网络在光束视角（BEV）空间学习向 MC 参考的加性修正。

---

## 研究问题与动机

- **质子治疗的精度与速度矛盾**：强度调制质子治疗（IMPT）对射程不确定性和解剖变化高度敏感；MC 模拟精度最高但计算太慢，无法用于迭代计划；传统解析铅笔束算法速度快，但在肺组织和骨/气界面处精度显著下降。
- **可微分剂量引擎的价值**：将物理引擎实现为可微分的 PyTorch 算子栈，使剂量相关目标可通过反向传播进行端到端优化，为梯度驱动的计划优化提供基础。
- **现有 AI 剂量方法的局限**：纯数据驱动方法直接从解剖预测剂量，缺乏显式物理基线，在训练分布外（如高能量远尾区）容易出现系统性偏差。
- **顶��学支持掩码的重要性被忽视**：此前工作常使用密度阈值掩码，而该文发现拓扑掩码（保留内部气腔如肠道气体和气管）对 IDD 距离和计划级精度影响巨大。

---

## 核心贡献（创新点）

1. **可微分 GPU 铅笔束剂量引擎**：基于 PyTorch 实现的双层高斯横向核 + Fermi–Eyges 异质性项 + 解析核晕，支持 autograd 路径，实现梯度驱动的 LUT 校准。
2. **零初始化残差架构**：残差 U-Net 从零点初始化，确保训练伊始即锚定在解析 PB 解上，而非直接预测剂量，保留了显式物理基线的稳定性。
3. **双阶段核校准方法**：第一阶段用信任域最小二乘逐深度拟合双高斯参数；第二阶段通过 autograd 路径以 Adam+余弦调度进行全 3D 剂量的梯度精修，显著改善远端边缘精度（如 164.45 MeV 处 MAE 从 0.77% 降至 0.20%）。
4. **多模态条件注入设计**：离散材料标签通过 4D 嵌入做空间条件，机器能量通过 64D 类别嵌入+MLP 做全局条件，束斑尺寸通过 2→64→64 MLP 编码后与能量向量相加——该设计在早期对照实验中显著优于标量/Fourier 特征输入。
5. **拓扑患者支持掩码**：移除最大连通外部空气分量并填充每层体轮廓，保留内部气腔，使隐藏测试的 beamlet MAE 降低 33.6%、IDD 距离降低 75.3%。

## 方法详解

**铅笔束引擎核心公式**：
- 每个束斑在 BEV 格点上处理，沿格点列的水等效深度为 $d(k) = \Delta \sum_{j<k} S_j - \frac{1}{2}\Delta S_k$（$S_j$ 为 SPR，体素中心约定），Bragg 峰随异质性发生侧向和纵向偏移。
- 每个束斑分裂为 $9\times9=81$ 个子束（四分 FWHM 间距），方差保持：$\sigma_{\text{sub}} = \sigma_{\text{spot}}/\sqrt{n}$。
- 横向核为可分离双高斯：$K(x,y) = (1-w)g(x;\sigma_1)g(y;\sigma_1) + w\,g(x;\sigma_2)g(y;\sigma_2)$，其中 $\sigma_1$ 为窄核心，$\sigma_2$ 为宽核晕，$w$ 为晕权重，均随深度变化；$Z(d)$ 提供每能量的振幅表。
- 剂量通过双线性重采样旋回患者坐标系。

**双阶段校准**：
- Stage 1：信任域最小二乘直接拟合 $(\sigma_1,\sigma_2,w)$ 和 $Z$。
- Stage 2：Adam（lr=0.03，余弦调度，每能量 150 次迭代，0.4 mm 深度采样），损失遮蔽低于 MC 峰 0.5% 的区域并加入二阶差分平滑先验。

**残差 U-Net**（RepVGG–U-Net，887,292 参数）：
- 输入通道：8 个连续通道（SPR−1、横向半径、归一化几何深度、归一化 WED、两个有符号侧向偏移、非负 SPR、峰归一化 PB 剂量）+ 材料标签 4D 嵌入；V2 新增第 9 通道：相对射程特征 $\delta_R = (\text{WED} - R_{\text{peak}}(E))/100$ mm。
- 能量编码为 114 个离散机能的 64D 类别嵌入；束斑宽度经 2→64→64 MLP 编码后与能量向量相加，广播至空间维度。
- 编解码器仅在侧向做降/升采样，保留完整束轴深度分辨率；编码器宽度 64/96/128/192/256，解码器较浅。
- 辅助修正头接在 192/128/96 通道解码阶段，全部零初始化。
- 输出：$\hat{D} = \max(0, D_{\text{PB}} + s\cdot\alpha\cdot r)$，$\alpha=0.25$，$s$ 为每束斑 PB 峰值。

**训练损失**：
- 主损失（患者空间）：$\mathcal{L}_{\text{pat}} = \langle e\rangle_{D_{\text{MC}}\neq 0} + 0.15\langle e\rangle_{D_{\text{MC}}>0.1\max(D_{\text{MC}})}$，其中 $e = |\hat{D}-D_{\text{MC}}|/\max(D_{\text{MC}})$，强调高剂量区。
- BEV 深度监督：$\mathcal{L} = \mathcal{L}_{\text{pat}} + 0.05\,\mathcal{L}_{\text{BEV}}$，$\mathcal{L}_{\text{BEV}}$ 为多尺度加权平均的遮蔽峰归一化 L₁ 损失，权重按尺度减半（1 : 1/2 : 1/4）。

**超参数**：AdamW（lr=5×10⁻⁴，wd=10⁻⁵），多项式衰减（幂 0.9），BF16 autocast，单位范数梯度裁剪，seed=12345，无 dropout/几何增强，每步随机采样 10 个束斑，EMA decay=0.999，训练 27 epoch。

**后处理**： corrected BEV 剂量旋转回患者网格并 clamp 至非负；拓扑掩码移除最大连通外部空气分量，填充每层体轮廓，保留内部气腔。

**MRI 路径**：独立训练的 nnU-Net 回归模型生成合成 CT（sCT），再送入同一剂量管道。

## 实验与结果

**数据集**：DoseRAD2026 质子数据集，67 训练例（32 腹部 + 35 胸部），8 验证例（4 腹部 + 4 胸部）；额外用 OpenGATE v10.1 + Geant4 v11.4 在水模中生成 MC 参考（10⁷/10⁸/10⁹ 初级 histories）。

**水模校准结果**：
- $10^8$ LUT（85 能量）：mean MAE 0.16%，gamma 99.8%（1%/1mm）；相比 $10^7$（43 能量）beam MAE −11.6%，IDD −7.9%，plan MAE −7.1%。
- $10^9$ refit 对比 $10^8$ 几乎无改善（beam MAE +0.05%），故选用 $10^8$ LUT。

**隐藏测试最终结果（CT 路径，27 epoch，拓扑掩码）**：

| 指标 | 数值 |
|------|------|
| Beamlet MAE | 0.0061 |
| IDD 距离 | 0.0020 |
| Plan MAE | 0.0044 |
| Gamma 通过率 (1%/1mm) | 98.81% |
| DVH 误差 | 0.431 |

**关键对比**：
- 拓扑掩码修正前后（13 epoch）：THB016 束 31 的 MAE 从 0.01568 → 0.00872（−44.4%），IDD 从 0.01948 → 0.00481（−75.3%）。
- 训练从 13 epoch 延长至 27 epoch：beam MAE −5.12%，IDD −8.99%，全部 8 例均改善。
- V2（9 通道，含 $\delta_R$）对比 V1：MAE −12.5%，IDD −5.6%。
- **MRI 路径**（13 epoch，固定掩码后）：beam MAE 0.0183，IDD 0.0151，plan MAE 0.0183，gamma 84.15%，DVH 3.806——显著劣于 CT 路径，印证 sCT 生成质量是主要瓶颈。

## 相关工作脉络

1. **Hong et al. (1996)** — 经典质子铅笔束算法，本文的核心物理引擎即在此基础上扩展，引入双高斯核与 Fermi–Eyges 项。
2. **Simkó et al. (2025, arXiv:2512.18863)** — 可微分光子剂量引擎，本文将其思想延伸至质子能区，并加入双阶段校准与残差修正。
3. **Kanematsu (2008)** — 高斯束模型的替代散射功率理论，为本文 Fermi–Eyges 异质性建模提供基础。
4. **RepVGG (Ding et al., CVPR 2021)** — 单阶段可重构卷积块，本文用于构建轻量 3D U-Net，训练时多分支、推理时融合为 11×11 深度卷积。
5. **nnU-Net (Isensee et al., Nat Methods 2021)** — 自配置生物医学分割框架，本文借用其残差编码器架构用于 MRI→sCT 回归。
6. **OpenGATE/Geant4** — MC 模拟生态，本文用于生成水模校准数据和_challenge 参考剂量。

## 局限性与未来方向

- **仅 8 例用于本地模型选择与调参**，结果可能存在过拟合风险；相同验证集上报告指标需谨慎解读。
- **Checkpoint 选择依赖 EMA 高剂量 MAE**，而 IDD 距离在训练中并非单调变化，应设计联合选择准则。
- **远尾区高能量下残余核晕响应不足**，增大横向拟合窗口可能高估核晕剂量，存在形状/支撑权衡，需更精细建模。
- **MRI 路径精度显著落后**（gamma 仅 ~84%），主要瓶颈在 sCT 生成质量而非剂量引擎本身。
- **最终 CT 推理耗时仍偏高**（~135 s/例），因仍基于 PyTorch/Python，向 C++/CUDA 迁移有显著加速空间。
- **未验证端到端计划优化能力**，可微分性在此仅用于校准，梯度驱动治疗计划尚未评估。

## 研究启发与可借鉴点

1. **零初始化残差 + 显式物理基线**的设计模式高度可迁移：任何有成熟解析解的计算任务（如 X 射线 CT 重建、超声成像）均可采用"解析基线 + 网络残差"的稳定训练策略。
2. **多模态条件注入的分层设计**（空间材料嵌入 + 全局能量/束斑嵌入）值得在其它多条件医学图像生成任务中复现。
3. **拓扑支持掩码**对剂量/图像后处理的影响远超密度阈值掩码，建议在类似任务中系统比较两种掩码策略。
4. **双阶段校准（最小二乘初 fit + autograd 精修）**可同时兼顾收敛稳定性和全局最优性，适用于其它可微分物理参数拟合场景。
5. **多尺度 BEV 深度监督**以低权重（0.05）辅助主损失，既正则化解码器中间层又不喧宾夺主，是可借鉴的正则化技巧。

## 关键术语表

**Pencil-Beam（PB）引擎**：将质子束分解为大量独立束斑（beamlets），每个束斑按解析核函数沉积剂量的剂量计算框架。

**蒙特卡洛（MC）**：基于 Geant4/OpenGATE 的粒子输运模拟，作为剂量计算的精度基准参考。

**光束视角（BEV）**：将患者坐标系旋转至每个束斑的法向平面，使 Bragg 峰在 BEV 空间中实现对齐，便于卷积网络处理。

**Stopping-Power Ratio（SPR）**：组织相对于水的电子阻止本领比，由 CT 值转换得到，用于计算水等效深度。

**水等效深度（WED）**：沿射线方向积分 SPR 得到的等效水量深度，决定 Bragg 峰位置。

**RepVGG–U-Net**：基于 RepVGG 块的轻量 3D U-Net，训练时多分支可重构，推理时融合为单一大核以提升速度。

**拓扑掩码（Topological mask）**：通过连通分量分析移除外部空气、填充体轮廓的支持掩码，保留内部气腔（肠道气体、气管等）。

**双高斯横向核（Double-Gaussian kernel）**：由窄核心和高斯核晕加权叠加构成的横向剂量沉积核，参数随深度变化。

## 可复现要素

- **数据集**：DoseRAD2026 质子数据集（challenge 专用），67 训练例 + 8 验证例；水模 MC 数据由 OpenGATE v10.1 + Geant4 v11.4 自行生成。
- **代码开源**：质子剂量引擎为开源 PyDoseRT 包的一部分（https://github.com/UMU-DDI/PyDoseRT）；挑战容器、训练代码、评估脚本、模型定义将在独立仓库公开（论文声明）。
- **关键超参**：AdamW lr=5×10⁻⁴，wd=10⁻⁵，多项式衰减 power=0.9，BF16 autocast，单位范数梯度裁剪，seed=12345，无 dropout/几何增强，每步 10 随机束斑，EMA decay=0.999，α=0.25，BEV 深度监督权重=0.05，27 epoch；LUT 选用 10⁸ histories（85 能量，31.7–200.8 MeV）。
- **sCT 模型**：独立训练的 nnU-Net 残差编码器回归模型（6 级编码器，32/64/128/256/320/320 通道），fold-all，1000 epoch，Nesterov SGD lr=0.01 momentum=0.99 wd=3×10⁻⁵。
- **评估协议**：Level 1（每束斑遮蔽 MAE + image-z IDD 距离）、Level 2（分层 plan MAE + 局部 gamma 1%/1mm + DVH 误差）；拓扑掩码在推理时应用。
