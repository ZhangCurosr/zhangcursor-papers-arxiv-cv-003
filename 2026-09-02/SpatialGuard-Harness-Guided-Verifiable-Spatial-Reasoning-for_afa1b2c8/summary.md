# 论文速读：SpatialGuard: Harness-Guided Verifiable Spatial Reasoning for Text-to-Image Generation

## 一句话总结
SpatialGuard 是一个结构化布局引导的复杂 3D 空间文生图框架，通过将空间意图外化为可编辑的 3D 布局状态，并构建"规划-实现-验证-修复"的闭环，在复杂多对象场景中显著提升空间关系保持能力，达到 SOTA 性能。

## 研究问题与动机
1. **缺乏可优化的空间布局中介**：现有方法缺乏一个在视觉采样前可优化、可验证的空间布局中间表示，导致复杂空间意图在多次生成迭代中约束衰减。
2. **多轮交互中的约束遗忘**：大模型在多轮规划、生成、评估和修正过程中容易出现上下文遗忘，早期确立的空间要求难以在后续交互中保留。
3. **空间关系易退化**：对象关系、遮挡、可见性和相机约束在渲染和修复过程中容易相互冲突或消失。
4. **隐式提示驱动的局限性**：传统方法仅依赖文本到图像模型的隐式推理，难以同时满足多个复杂空间约束。

## 核心贡献（创新点）
1. **提出 SpatialGuard 框架**：首次将 agent harness 概念引入文生图流水线，构建跨轮次的空间约束执行机制，与已有布局引导方法（仅作为静态条件）的本质区别在于将布局视为可编辑的状态并实现闭环验证与修复。
2. **设计 Spatial Layout Architect**：将输入文本解析为图像合成导向的 3D 结构化布局，与已有方法仅提取静态布局条件的本质区别在于该布局可作为跨模块共享的可查证中间表示持续优化。
3. **引入 Visual Alignment Critic**：对对象放置、关系、可见性和相机约束进行结构化验证并将偏差转化为可执行的修复操作，与已有评分模型仅输出标量分数的本质区别在于定位到具体布局字段并提供定向修复指令。
4. **构建 Layout Harness**：通过规则约束、工具调用、共享知识和反馈循环四个机制持久化空间约束，与已有方法依赖对话历史的本质区别在于将约束外化为可检索、可更新的显式状态。
5. **SOTA 实验结果**：在七个空间维度上全面超越现有基线（Overall 9.37 vs 最佳基线 7.90），最大提升达 2.18 分（Depth），证明显式布局引导的有效性。

## 方法详解
1. **布局状态表示**：第 t 轮布局状态 $L^{(t)} = (\{(c_i, x_i^{(t)}, s_i^{(t)}, \alpha_i^{(t)})\}_{i=1}^N, \kappa^{(t)})$，其中 $c_i$ 为对象类别，$x_i^{(t)}$ 为 3D 位置，$s_i^{(t)}$ 为布局可读尺度，$\alpha_i^{(t)}$ 为方位角，$\kappa^{(t)}$ 为相机参数向量。
2. **Spatial Layout Architect**：$L^{(0)} = \mathcal{A}_s(p, \mathcal{O}, \mathcal{C}, a)$ 初始化布局；$L^{(t+1)} = \mathcal{A}_s(p, \mathcal{O}, \mathcal{C}, a, L^{(t)}, \Delta^{(t)})$ 根据修复反馈更新布局，使用 GPT-5 实现。
3. **Visual Realizer**：$I^{(t)} = \mathcal{G}(p, a, \rho(L^{(t)}), \psi(p, L^{(t)}))$，将布局渲染为全局几何、生成实例级掩码、对齐对象区域与提示 token，调用 FLUX.1-dev 生成候选图像。
4. **Visual Alignment Critic**：$(v^{(t)}, \Delta^{(t)}) = \mathcal{A}_c(p, \mathcal{C}, L^{(t)}, I^{(t)})$，结构化验证记录 $v^{(t)}$ 列出通过/失败的约束，修复反馈 $\Delta^{(t)}$ 定位到具体布局字段。
5. **Layout Harness 四机制**：
   - 规则约束：将空间要求转化为可检查的边界
   - 工具调用：$\mathbf{u}^{(t)} = \Gamma(v^{(t)}, \Delta^{(t)}, H^{(t)})$，支持平移、缩放、支撑调整、遮挡控制、可见性恢复、焦距调整等操作
   - 共享知识：$M^{(t)}$ 记录对象清单、解析的空间谓词、历史布局状态和修复轨迹
   - 反馈循环：将验证失败重新注入规划阶段，持续迭代直至无失败约束

## 实验与结果
1. **评估设置**：使用 Gemini 2.5 Pro、Qwen3-VL、Grok 4 作为 VLM 评估器，在 Presence、Position、Relation、Depth、Scale、Support、Framing 七个维度评分（1-10 分）。
2. **主要结果**：SpatialGuard Overall 得分 **9.37**，全面超越所有基线。最佳基线 HunyuanImage-2.1 得分为 7.90，差距 1.47 分。
3. **关键提升**：Depth (+2.18)、Support (+1.81)、Scale (+1.48)、Relation (+1.42)、Presence (+0.67)。
4. **消融实验**：移除任一组件均导致性能下降；完整系统各组件协同作用，Architect 缺失影响 Position/Relation，Realizer 缺失影响 Position/Support，Critic 缺失影响 Relation/Depth/Framing，Harness 缺失影响 Overall。
5. **定性分析**：基线方法在复杂场景中常出现对象缺失、部分可见、方向关系违反等问题，SpatialGuard 能同时保持对象完整性、相对位置和方向关系。

## 相关工作脉络
1. **Janus-Pro-R1 / T2I-R1**：通过强化学习和思维链提升语义对齐，但空间关系仍依赖隐式模型行为；本文方法通过显式布局状态实现可验证的空间一致性。
2. **LayoutGPT**：使用语言模型进行组合视觉规划，但布局作为静态条件传入生成器；本文方法将布局视为可编辑状态并实现闭环验证与修复。
3. **SeeThrough3D / SceneDesigner**：引入遮挡感知的 3D 布局条件和 9-DoF 位姿控制；本文方法强调布局的可优化性和跨轮约束持久化，而非单次静态条件。
4. **Self-Cross**：通过扩散引导减少相似对象混淆；本文方法通过结构化验证和定向修复解决对象关系违反问题。
5. **VASA / SceneWeaver**：在视觉分割和 3D 场景生成中引入 harness 设计；本文首次将 harness 概念系统性地引入文生图领域并实现空间约束的跨轮持久化。

## 局限性与未来方向
1. **适用场景限制**：当前框架主要适用于可通过对象列表、关系、可见性约束和相机参数表达的空间场景，对高度抽象艺术意图或模糊空间描述的处理有限。
2. **推理成本较高**：由于需要多轮规划、验证和修复，推理成本高于单次直接调用文生图模型。
3. **视觉质量依赖底层模型**：最终图像质量仍取决于底层生成器 FLUX.1-dev 的能力。
4. **未来方向**：可扩展工具库以支持更精细的物理交互，通过更轻量级的验证策略提升效率。

## 研究启发与可借鉴点
1. **Harness 设计范式可迁移**：规则约束、工具调用、共享知识、反馈循环四机制可复用到视频生成、3D 场景生成等需要多轮迭代和约束保持的任务。
2. **显式布局中间表示的价值**：将语言意图外化为可编辑的结构化状态，有效解耦语言理解、视觉合成和结果评估，该思路可应用于任何需要空间对齐的生成任务。
3. **结构化验证+修复闭环**：将偏差定位到具体字段并提供定向修复指令，而非仅输出标量分数，这一设计可提升迭代生成系统的可解释性和可控性。
4. **工具调用机制设计**：平移、缩放、支撑调整、遮挡控制等工具的设计模式可复用到其他需要空间操作的生成系统。
5. **跨轮约束持久化**：通过共享知识状态而非对话历史保存决策轨迹，可避免大模型上下文遗忘问题，对多轮对话生成系统具有借鉴价值。

## 关键术语表
**SpatialGuard**：结构化布局引导的复杂 3D 空间文生图框架，实现从文本空间意图到可验证视觉生成的闭环。
**Layout Harness**：组织规则约束、工具调用、共享知识和反馈循环的执行层机制，用于跨轮次持久化空间约束。
**Spatial Layout Architect**：将输入文本解析为图像合成导向的 3D 结构化布局的组件，使用 GPT-5 实现。
**Visual Realizer**：将布局状态转换为渲染几何、实例掩码和候选图像的组件，基于 FLUX.1-dev 实现。
**Visual Alignment Critic**：对候选图像进行结构化验证并输出修复反馈的组件，定位到具体布局字段。
**规则约束**：将语言中的空间要求转化为可检查的布局边界，支持关系、支撑、可见性等约束。
**共享知识**：跨轮次持久存储对象清单、空间谓词、历史布局和修复轨迹的机制，避免上下文遗忘。
**反馈循环**：将验证失败重新注入规划阶段的机制，通过工具调用执行修复并持续迭代。
